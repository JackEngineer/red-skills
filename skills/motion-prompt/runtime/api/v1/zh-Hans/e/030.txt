// 示例内容：相机绕主体沿圆弧运动，人物保持居中，身后的树和建筑横向扫过。
// 动效规格：
//   - 相机：以人物为中心，沿半径 6 m 的圆周运动；人物在前方 9 m，角度从 -0.95 rad → +0.95 rad（-54° → +54°，共约 109°）。
//   - 方向：始终朝向圆心，yaw = -angle；高度 1.7 m，俯仰角固定为 -0.07 rad，约向下 4°。
//   - 时间：0.5 s 至 3.6 s，历时 3.1 s，使用三次方缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
//   - 主体：人物不动，脸上的白点随角度横移；地面以半径 1.3 m 的虚线圆标记。
//   - 背景：12 棵树均匀分布在半径 10 m 的圆周上，相机环绕时从人物身后横穿。
//   - 返回：在 3.6–4.2 s 保持，最后 0.5 s 交叉淡化回起点；右上角显示角度，-54° → +54°。
// 适用场景：适合立体展示人物或产品，或强调入场和关键时刻。
// 标签：环绕、弧线运镜、圆形、360° 旋转、绕主体旋转、环绕旋转、运镜
// 尺寸：539x208 px · 循环时长：9.4 秒
// 依赖：共用辅助代码 camera -> ../../kit/camera.js
// 动态示例：https://jackengineer.github.io/motion-prompt/?lang=zh-Hans#030
// 以上资源路径相对于本规格文件。
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用方已清空画布并用 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面只取决于 u。
// 以下为元素代码。CELLS、常量和辅助函数在 kit 中。

// @element 06
CELLS[5] = shot(camCell((k, w, h, p) => {
  const a = lerp(-0.95, 0.95, p), R = 6, P0 = [0, 0, 9];
  const c = cam({ x: P0[0] + Math.sin(a) * R, z: P0[2] - Math.cos(a) * R, yaw: -a, y: 1.7, pitch: -0.07 });
  world(k, w, h, c, {
    person: { z: 9, face: a }, ring: [0, 9, 10], buildings: true, trees: false,
    after: (kk, cc) => { kk.strokeStyle = C.blueM; kk.lineWidth = 2; kk.setLineDash([5, 5]); kk.beginPath(); for (let i = 0; i <= 48; i++) { const b = i / 48 * Math.PI * 2; const q = proj(cc, Math.sin(b) * 1.3, 0, 9 + Math.cos(b) * 1.3); i ? kk.lineTo(q.x, q.y) : kk.moveTo(q.x, q.y); } kk.stroke(); kk.setLineDash([]); }
  });
}, p => `${Math.round(lerp(-0.95, 0.95, p) * 57.3)}°`.replace(/^(\d)/, '+$1'), 0.5, 3.6));
