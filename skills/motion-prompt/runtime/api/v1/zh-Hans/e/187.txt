// 淡出到黑场 / 英文名：Fade to black
// 素材包：camera2 (镜头运动与转场（第 2 弹）) · 元素 19 · 类别：转场与剪辑
// 示例内容：整幅画面逐渐变黑，下一场景再从黑色中亮起。
// 动效规格：
//   - 淡出：1.4 s 至 2.6 s（1.2 s），在离场画面上叠加黑色（rgb(20,20,24)），不透明度 0 → 100%，二次缓入缓出（约为 cubic-bezier(0.45,0,0.55,1)）。
//   - 全黑：2.6 s 至 3.1 s 完全黑屏；2.9 s 时通过硬切换入下一画面，切换不可见。
//   - 淡入：3.1 s 至 4.3 s（1.2 s），黑色不透明度按相同缓动从 100% → 0。
//   - 相机：两幅画面中均固定（A 高度 1.4 m；B 高度 1.6 m、俯仰角 +0.1 rad）；主体也不移动。
//   - 每 4.7 s 交替 A→B 和 B→A（往返 9.4 s）；右上角读数为“淡出” / “淡入”；取景器标记在黑屏上方保持可见。
// 适用场景：适合章节间隔、较长时间流逝或故事结尾。
// 标签：淡出至黑、淡出、淡入、黑色、收尾、转场
// 尺寸：539x208 px · 循环时长：9.4 秒
// 依赖：共用辅助代码 camera2 -> ../../kit/camera2.js
// 动态示例：https://jackengineer.github.io/motion-prompt/?lang=zh-Hans#187
// 以上资源路径相对于本规格文件。
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用方已清空画布并用 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面只取决于 u。
// 以下为元素代码。CELLS、常量和辅助函数在 kit 中。

// @element 19
CELLS[18] = shot(abCell((k, w, h, u, A, B) => {
  const out = eIOs(P(u, 1.4, 2.6)), inn = eIOs(P(u, 3.1, 4.3));
  if (u < 2.9) A(k, w, h); else B(k, w, h);
  const a = u < 2.9 ? out : 1 - inn;
  if (a > 0) { k.fillStyle = `rgba(20,20,24,${a.toFixed(3)})`; k.fillRect(0, 0, w, h); }
}, u => u < 2.9 ? '淡出' : '淡入'));
