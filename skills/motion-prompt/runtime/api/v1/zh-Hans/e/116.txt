// 双色调 / 英文名：Duotone
// 素材包：photo (摄影效果、光线与风格) · 元素 20 · 类别：色调与后期风格
// 示例内容：同一片风景的颜色被替换为仅由两种颜色构成的色阶，暗部为靛蓝，亮部为粉色。
// 动效规格：
//   - 场景 3：左侧为半身像（头部中心 x 140、y 82，半径 28 px），右侧有山丘、房屋、树木和太阳（x 432、y 54，半径 15 px）。
//   - 两种颜色：暗端 #1F2A5C，亮端 #FF9FB2。
//   - 转换：根据每种颜色的亮度 L，计算 t = ((L − 70) / 180)^2.4，并按 t 混合两种颜色（拉开亮部色阶）。
//   - 时间：效果在 0.4 s 至 1.4 s 之间显现，保持至 4.0 s，并在 4.8 s 前消失（单次 = 5 s，三次缓入缓出，约为 cubic-bezier(0.65,0,0.35,1)）。
// 适用场景：适合用品牌色统一海报、音乐封面或社交媒体图片。
// 标签：双色调、双色调、渐变映射、颜色叠加、海报、图形
// 尺寸：539x208 px · 循环时长：5 秒
// 依赖：共用辅助代码 photo -> ../../kit/photo.js
// 动态示例：https://jackengineer.github.io/motion-prompt/?lang=zh-Hans#116
// 以上资源路径相对于本规格文件。
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用方已清空画布并用 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面只取决于 u。
// 以下为元素代码。CELLS、常量和辅助函数在 kit 中。

// @element 20
CELLS[19] = cell((k, u) => {
  const a = env(u);
  const DUO = mapPal(BASE, c => mixc('#1F2A5C', '#FF9FB2', Math.pow(clamp((lum(c) - 70) / (250 - 70)), 2.4)));
  stageLand(k, pal(BASE, DUO, a));
});
