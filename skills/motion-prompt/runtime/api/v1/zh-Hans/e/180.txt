// 过肩镜头 / 英文名：Over-the-shoulder
// 素材包：camera2 (镜头运动与转场（第 2 弹）) · 元素 12 · 类别：角度与构图
// 示例内容：一个人的后脑勺和肩膀位于画面边缘，越过肩膀可见另一个人；前景模糊，主体清晰。
// 动效规格：
//   - 取景：前景人物的后脑勺和肩膀（灰色，左侧 0.62 m，距离 1.15 m）占据左边缘；越过肩膀可见另一人物（蓝色，右侧 0.32 m，距离 3.1 m）。
//   - 焦点：前景肩膀模糊 2.6 px，另一人物清晰，取景范围为胸部以上。
//   - 相机：高度 1.55 m，偏航角 +0.05 rad；在 0.5 s 至 3.4 s 之间缓慢推进 0 m → 0.35 m（三次缓入缓出，约为 cubic-bezier(0.65,0,0.35,1)）。
//   - 另一人物的手臂和腿按 0.35·sin(u×5) rad 摆动，仿佛在说话。
//   - 返回：在 3.4–4.2 s 保持，最后 0.5 s 交叉淡化回起点；右上角读数为“过肩”。
// 适用场景：适合交代对话中人物的相对位置，并突出对方的表情。
// 标签：过肩镜头、过肩镜头、对话、交谈、越肩构图、双人镜头、拍摄角度
// 尺寸：539x208 px · 循环时长：9.4 秒
// 依赖：共用辅助代码 camera2 -> ../../kit/camera2.js
// 动态示例：https://jackengineer.github.io/motion-prompt/?lang=zh-Hans#180
// 以上资源路径相对于本规格文件。
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用方已清空画布并用 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面只取决于 u。
// 以下为元素代码。CELLS、常量和辅助函数在 kit 中。

// @element 12
CELLS[11] = shot(camCell((k, w, h, p, u) => {
  world(k, w, h, cam({ z: lerp(0, 0.35, p), y: 1.55, yaw: 0.05 }), {
    person: { x: 0.32, z: 3.1, walk: 0.35 * Math.sin(u * 5) }, blurFg: 2.6,
    extra: [[-0.62, 0, 1.15, (kk) => { kk.fillStyle = C.g4; kk.beginPath(); kk.arc(0, 1.63, 0.17, 0, 7); kk.fill(); rr(kk, -0.34, 0.9, 0.68, 0.6, 0.14); kk.fill(); }, true]]
  });
}, p => '过肩'));
