// 慢动作 / 英文名：Slow motion
// 素材包：camera (镜头运动与转场) · 元素 13 · 类别：拍摄方式与时间效果
// 示例内容：固定镜头前，人物缓慢起跳和落下，树叶也缓缓飘落，整个动作被拉长。
// 动效规格：
//   - 相机：完全固定，高 1.3 m，只有主体运动。
//   - 主体：7 m 处的人物用 3.8 s 完成一次跳跃，从 0.5 s 至 4.3 s；height = 4q(1-q)×1.1 m，抛物线最高点为 1.1 m，q 随时间线性变化。
//   - 腾空时双臂举起，起跳前静止 0.5 s，落地后静止 0.4 s。
//   - 树叶：9 片叶子在 4.7 s 内从 3.4 m 高处旋转着落地，每片相差周期的 1/9。
//   - 右上角显示“120fps ×0.25”，表示播放时长拉长 4 倍。
//   - 无停留、无交叉淡化，每 4.7 s 无缝循环。
// 适用场景：适合让观众仔细看短暂动作或表情，或强调情绪高点。
// 标签：慢动作、慢动作、慢镜头、高帧率、每秒 120 帧、时间拉伸、跳跃
// 尺寸：539x208 px · 循环时长：9.4 秒
// 依赖：共用辅助代码 camera -> ../../kit/camera.js
// 动态示例：https://jackengineer.github.io/motion-prompt/?lang=zh-Hans#037
// 以上资源路径相对于本规格文件。
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用方已清空画布并用 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面只取决于 u。
// 以下为元素代码。CELLS、常量和辅助函数在 kit 中。

// @element 13
CELLS[12] = shot((k, w, h, u) => {
  const q = P(u, 0.5, 4.3);
  world(k, w, h, cam({ y: 1.3 }), { person: { z: 7, y: jumpY(q), armUp: q > 0 && q < 1 }, extra: leaves(u, 1) });
  return '120fps ×0.25';
});
