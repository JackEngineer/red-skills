// 示例内容：相机原地从左向右转动；由于只有旋转，近景和远景在画面中横移的角度相同。
// 动效规格：
//   - 相机：位置固定，高 1.5 m；只改变偏航角，从 -0.32 rad → +0.32 rad（-18° → +18°，共约 37°）。
//   - 时间：0.5 s 至 3.4 s 旋转，历时 2.9 s，使用三次方缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
//   - 主体：人物身高约 1.8 m，静止站在前方 8 m，在画面中从右向左移动。
//   - 无视差：山、建筑、树和人物均移动相同角度；539×208 卡片上的焦距为 330 px。
//   - 返回：在 3.4–4.2 s 保持，最后 0.5 s 交叉淡化回起始画面，每轮 4.7 s。
//   - 右上角以整数度显示角度，-18° → +18°。
// 适用场景：适合展现宽阔场地，或将注意力从场景一侧转移至另一侧。
// 标签：水平摇镜、水平摇镜、偏航、旋转、水平、运镜、显现
