// 素材包：photo (摄影效果、光线与风格) · 元素 03 · 类别：布光与时段
// 示例内容：按明亮的暮色天空设置曝光后，人物、建筑、路灯和树木变成没有细节的纯黑形状，只有天空保持明亮。
// 动效规格：
//   - 场景 1：地平线位于 y 150，前方为头肩人像（头部中心 x 270、y 78，半径 29 px，无五官或头发）。
//   - 天空：顶部 #FAF9F7 → #FFEDC4，地平线附近（y 92–150）为 #FFCF73 色带。
//   - 除天空外，所有物体变成 #2A2D36，远处山丘为 #4A4546；人物为 #22252D。
//   - 太阳：半径 20 px，位于 x 404，从 y 60 降至 y 128，一半被山丘遮住。
//   - 右上角读数：±0.0 EV → −2.0 EV。
//   - 时间：效果在 0.4 s 至 1.4 s 之间显现，保持至 4.0 s，并在 4.8 s 前消失（单次 = 5 s，三次缓入缓出，约为 cubic-bezier(0.65,0,0.35,1)）。
// 适用场景：适合以夕阳或明亮窗户为背景，依靠形状和姿态表达画面。
// 标签：剪影、逆光拍摄、日落、逆光摄影、黑色剪影、曝光不足
// 尺寸：539x208 px · 循环时长：5 秒
// 依赖：共用辅助代码 photo -> ../../kit/photo.js
// 动态示例：https://jackengineer.github.io/motion-prompt/?lang=zh-Hans#099
// 以上资源路径相对于本规格文件。
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用方已清空画布并用 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面只取决于 u。
// 以下为元素代码。CELLS、常量和辅助函数在 kit 中。

// @element 03
CELLS[2] = cell((k, u) => {
  const a = env(u), INK = '#2A2D36';
  const SILH = mapPal(BASE, () => INK);
  Object.assign(SILH, { sky: '#FFEDC4', sky2: '#FFCF73', far: '#4A4546', sun: BASE.sun, glow: BASE.glow });
  stagePortrait(k, pal(BASE, SILH, a), { sun: [404, lerp(60, 128, a), 20, a] });
  bust(k, PX, PY, PR, mixc(BASE.person, '#22252D', a));
  hud(k, `${(-2 * a).toFixed(1).replace('-0.0', '±0.0')} EV`);
});
