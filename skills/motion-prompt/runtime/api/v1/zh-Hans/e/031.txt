// 升镜头 / 英文名：Crane up
// 素材包：camera (镜头运动与转场) · 元素 07 · 类别：镜头运动
// 示例内容：相机一边上升一边向下俯拍，最终从上方看向人物。
// 动效规格：
//   - 相机：从 1.4 m 上升至 9 m，同时向前移动 0 m → 1.5 m。
//   - 方向：向下倾斜，让前方 8 m 的人物始终在画面内；pitch = -0.86 × atan2(height - 1.0, 8 - forward)，约 -2.5° → -44°。
//   - 时间：0.5 s 至 3.4 s，历时 2.9 s，使用三次方缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
//   - 主体：人物不动，随着相机上升而变小，地面网格铺满画面，地平线从顶部离开。
//   - 返回：在 3.4–4.2 s 保持，最后 0.5 s 交叉淡化回起始画面，每轮 4.7 s。
//   - 右上角显示高度，↑ 1.4m → ↑ 9.0m。
// 适用场景：适合在场景结束时拉离人物，或展现场地的广阔规模。
// 标签：摇臂摄影、升镜头、摄影摇臂、镜头上升、上升、高角度俯拍、运镜
// 尺寸：539x208 px · 循环时长：9.4 秒
// 依赖：共用辅助代码 camera -> ../../kit/camera.js
// 动态示例：https://jackengineer.github.io/motion-prompt/?lang=zh-Hans#031
// 以上资源路径相对于本规格文件。
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用方已清空画布并用 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面只取决于 u。
// 以下为元素代码。CELLS、常量和辅助函数在 kit 中。

// @element 07
CELLS[6] = shot(camCell((k, w, h, p) => {
  const y = lerp(1.4, 9, p), z = lerp(0, 1.5, p);
  world(k, w, h, cam({ y, z, pitch: -0.86 * Math.atan2(y - 1.0, 8 - z) }), { person: { z: 8 } });
}, p => `↑ ${lerp(1.4, 9, p).toFixed(1)}m`));
