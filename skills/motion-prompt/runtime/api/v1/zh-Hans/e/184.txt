// 动效规格：
//   - 相机：把前方 1.3 m 处面孔的右眼（中心左侧 0.06 m，高 1.66 m）放在画面中心；相机不移动。
//   - 焦距：610 px → 2040 px（显示为 44mm → 148mm，约 3.3×）；f = 610 × (2040/610)^p，其中 p 在 0.5 s 至 3.4 s 之间采用三次缓入缓出（约为 cubic-bezier(0.65,0,0.35,1)）。
//   - 面孔：蓝色头部（半径 0.16 m），白色眼睛（椭圆 0.045×0.028 m）、深色瞳孔（半径 0.016 m）、高光和白色眉毛；开始为整张脸的特写（头部宽约 150 px），结束时只有双眼充满画面。
//   - 背景：树木和建筑模糊 3 px，随着镜头拉近逐渐离开画面。
//   - 返回：在 3.4–4.2 s 保持，最后 0.5 s 交叉淡化回起点；右上角读数显示焦距和景别（44mm 特写 → 148mm 大特写）。
// 适用场景：适合情绪高潮，或让观众注意到细小的关键细节。

// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用方已清空画布并用 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面只取决于 u。

// @element 16
CELLS[15] = shot(camCell((k, w, h, p) => {
  const f = 610 * Math.pow(2040 / 610, p);
  world(k, w, h, cam({ f, x: -0.06, y: 1.66 }), {
    blurBg: 3, trees: true,
    extra: [[0, 0, 1.3, (kk) => {
      person(kk, 1);
      [[-0.06, 1.66], [0.06, 1.66]].forEach(([x, y]) => { kk.fillStyle = '#fff'; kk.beginPath(); kk.ellipse(x, y, 0.045, 0.028, 0, 0, 7); kk.fill(); kk.fillStyle = C.ink; kk.beginPath(); kk.arc(x + 0.008, y, 0.016, 0, 7); kk.fill(); kk.fillStyle = '#fff'; kk.beginPath(); kk.arc(x + 0.014, y + 0.007, 0.005, 0, 7); kk.fill(); kk.strokeStyle = '#fff'; kk.lineWidth = 0.012; kk.beginPath(); kk.arc(x, y + 0.02, 0.05, Math.PI * 1.15, Math.PI * 1.85); kk.stroke(); });
    }]]
  });
}, p => `${mm(610 * Math.pow(2040 / 610, p))} ${p > 0.85 ? '大特写' : '特写'}`));
