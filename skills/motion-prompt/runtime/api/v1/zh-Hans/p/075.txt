请使用“吸顶页头（英文名：Sticky header）”，它属于“落地页与网页效果”素材包。
Motion Prompt #075

含义：滚动时页头停留在屏幕顶部
示例内容：公告条随页面滚走，下方页头则停留在顶部边缘，正文从页头下方滚过。
动效规格：
- 滚动：0.4–1.3 s 从 0→110 px，1.9–2.8 s 从 110→250 px，3.4–4.4 s 从 250→0（三次方缓入缓出）。
- 顶部为高 22 px 的藏青色公告条，下方是高 34 px 的页头（标志、三个菜单项、按钮）。
- 页头位置 = max(22 − scroll, 0)：公告条消失后，页头停在顶部边缘（position: sticky; top: 0）。
- 继续滚动 24 px 的过程中，页头下方 12 px 阴影的不透明度从 0 增至 0.16。
- 正文（照片、标题、三张卡片）正常滚动，从页头下方经过。
适用场景：适合长页面，让菜单和主要操作按钮始终便于使用。
