Motion Prompt #203

含义：金与黑、放射直线与左右对称
示例内容：同一张线稿变成金黑配色的海报：直线光芒从太阳向外发散，几何直线装饰近乎对称排列。
动效规格：
- 配色：以金色和黑色为主
- 外观：放射状直线光芒、几何直线和近乎对称的装饰
- 氛围：1920 年代海报（示例无文字）
- 示例：将同一张基础草图（山丘上的房屋、树和太阳的线稿）作为参考交给图像模型，按此风格重绘。0.5 s 至 1.35 s，以斜向擦除从草图切换为该风格；画面缓慢放大至 1.045x，持续到 4.0 s；4.0 s 至 4.5 s 淡回草图（单次循环 = 4.7 s，cubic ease-in-out）
适用场景：适合奢华、古典、华丽的画面。
