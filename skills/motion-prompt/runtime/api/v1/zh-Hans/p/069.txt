Motion Prompt #069

含义：加载时以灰色块预示内容布局
示例内容：点击重新加载后，列表变成相同形状的灰色块，表面扫过亮光；加载结束后恢复内容。
动效规格：
- 542×191 卡片，循环周期 4.5 s。两行列表，每行包含 96×56 图片和三行文字。光标在 1.0 s 点击右上角重新加载图标。
- 1.05–1.2 s 内（线性），内容变为位置、尺寸相同的灰色 #e9e7e5 圆角块。
- 扫光：宽 160 的白色带（边缘透明，中央不透明度 0.75）每 0.9 s 从 x −200 扫至 x 742，仅绘制在灰块范围内。
- 内容在 3.0–3.3 s 恢复（线性）。
适用场景：适合需要短暂加载的列表或卡片，让用户在等待时看到布局。
