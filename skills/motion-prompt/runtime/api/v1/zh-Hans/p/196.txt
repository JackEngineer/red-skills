Motion Prompt #196

含义：轮廓线加平涂色块的木版画
示例内容：同一张线稿变成江户时代的彩色木版画：房屋变为日式瓦顶屋，树变为松树，太阳变为红色圆盘，天空从顶部的深靛蓝向下渐淡。
动效规格：
- 媒介：江户时代的多色木版画
- 外观：细而均匀的黑色轮廓、平涂色块、各色版之间轻微错位，保留和纸纤维与印刷不均的质感
- 天空：顶部深靛蓝向下渐淡，横贯一条雾带；太阳为红色圆盘（示例不包含富士山、海浪、人物或文字）
- 示例：将同一张基础草图（山丘上的房屋、树和太阳的线稿）作为参考交给图像模型，按此风格重绘。0.5 s 至 1.35 s，以斜向擦除从草图切换为该风格；画面缓慢放大至 1.045x，持续到 4.0 s；4.0 s 至 4.5 s 淡回草图（单次循环 = 4.7 s，cubic ease-in-out）
适用场景：适合用鲜明的平涂色块和线条表现日本题材。
