Motion Prompt #210

含义：用小立方体堆成的3D
示例内容：同一张线稿变成小立方体堆叠的 3D 微缩场景；房屋、树、太阳和山丘都由立方体组成，顶面受光，侧面有阴影。
动效规格：
- 构造：所有内容均用堆叠的小立方体搭建为 3D 模型
- 外观：每个立方体的顶面和侧面有明暗变化，呈现 3D 体积；以略微俯视的角度渲染
- 注意：并非平面的像素画（#209）
- 示例：将同一张基础草图（山丘上的房屋、树和太阳的线稿）作为参考交给图像模型，按此风格重绘。0.5 s 至 1.35 s，以斜向擦除从草图切换为该风格；画面缓慢放大至 1.045x，持续到 4.0 s；4.0 s 至 4.5 s 淡回草图（单次循环 = 4.7 s，cubic ease-in-out）
适用场景：适合游戏风格的 3D 画面或可爱的微缩场景。
