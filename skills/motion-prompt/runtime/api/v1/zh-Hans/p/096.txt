Motion Prompt #096

含义：元素轻柔地上下浮动
示例内容：标题旁的手机、爱心徽标和评分标签各自错开节奏轻轻浮动，手机下方阴影随之缩放。
动效规格：
- 手机（92 × 132）：y = −8·sin(2πt/2.4)，每 2.4 s 浮动一次；正弦曲线让两端动作放慢。
- 爱心徽标（半径 20）：y = −6·sin(2πt/1.6 + 1.2)。评分标签（76 × 30）：y = −6·sin(2πt/2.4 + 2.4)。
- 手机下方阴影为 54 × 6 椭圆，尺寸和不透明度均乘以 (1 + y/40)，因此手机升起时阴影缩小并变淡。
- 两个周期（2.4 s 和 1.6 s）都能整除 4.8 s，因此循环没有接缝。
适用场景：适合为产品图、应用模型或装饰图标增加轻柔动感。
