Motion Prompt #180

含义：越过一人的肩膀拍另一人
示例内容：一个人的后脑勺和肩膀位于画面边缘，越过肩膀可见另一个人；前景模糊，主体清晰。
动效规格：
- 取景：前景人物的后脑勺和肩膀（灰色，左侧 0.62 m，距离 1.15 m）占据左边缘；越过肩膀可见另一人物（蓝色，右侧 0.32 m，距离 3.1 m）。
- 焦点：前景肩膀模糊 2.6 px，另一人物清晰，取景范围为胸部以上。
- 相机：高度 1.55 m，偏航角 +0.05 rad；在 0.5 s 至 3.4 s 之间缓慢推进 0 m → 0.35 m（三次缓入缓出，约为 cubic-bezier(0.65,0,0.35,1)）。
- 另一人物的手臂和腿按 0.35·sin(u×5) rad 摆动，仿佛在说话。
- 返回：在 3.4–4.2 s 保持，最后 0.5 s 交叉淡化回起点；右上角读数为“过肩”。
适用场景：适合交代对话中人物的相对位置，并突出对方的表情。
