Motion Prompt #219

含义：把一个问题按分支拆解
示例内容：从左侧的“?”方框开始，树状结构向右按 1 → 2 → 4 分支，以折线连接。
动效规格：
- 根节点：左侧（x = 82）为 66×50 px 的蓝色方框，内有白色“?”；0.4 s 开始，用 0.3 s 弹性出现（ease-out-back）
- 第 2 层：x = 248 处有两个 76×34 px 的中蓝色方框；连接折线在 0.75 s 至 1.15 s 绘出，方框分别在 1.05 s 和 1.13 s 弹性出现
- 第 3 层：x = 426 处有四个 92×26 px 的浅蓝色方框；连接线从 1.35 s 开始，间隔 0.06 s，各用 0.4 s 绘出；方框从 1.65 s 开始，间隔 0.08 s 弹性出现
- 连接线：灰色、3 px，从父节点右边缘出发，在中途向上或向下折弯，接入子节点左边缘（cubic ease-in-out 绘制）
- 结束：整个图形在 4.1 s 至 4.5 s 淡出，卡片保持空白，直到 4.7 s 循环重新开始
适用场景：适合完整拆解问题或目标，列出原因或行动。
