Motion Prompt #126

含义：沿设定的曲线移动
示例内容：纸飞机沿虚线路径飞行，随路径转向，途中绕一个环。
动效规格：
- 每轮 4.7 s，从画面左侧外飞到右侧外。路径为 x = 270 + 112θ − 150·sinθ, y = 106 − 74·cosθ，θ = −π→π，在画面上部中央形成一个环。
- θ 与时间成正比推进，因此沿路径的速度并不恒定，环内看起来较慢。
- 纸飞机转向与路径一致，angle = atan2(74·sinθ, 112 − 150·cosθ)。
- 路径预先以点线显示（宽 6，虚线 2/15）。后方跟随 24 段薄荷绿尾迹，每段间隔 θ 的 0.03，越往后越细、越淡。
适用场景：适合需要沿指定路线运动的对象，例如飞行物、汽车或地图上的旅程。
