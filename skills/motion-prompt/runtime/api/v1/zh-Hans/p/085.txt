Motion Prompt #085

含义：从点击位置扩散的圆形波纹
示例内容：每次点击都会从点击处扩散出白色圆形，铺满按钮后淡出。
动效规格：
- 按钮 280 × 56，橙色，圆角 10。在 0.7 s（中心偏左）和 2.9 s（中心偏右）点击。
- 圆心位于点击位置；半径在 0.6 s 内从 0 增至点击处到按钮最远角的距离（三次方缓出）。
- 白色，不透明度 0.4，在点击后 0.3–0.8 s 淡至 0。
- 圆形裁切在按钮内（overflow: hidden）；文字标签位于其上方。
适用场景：适合在按钮或列表项的实际按下位置给出确认反馈。
