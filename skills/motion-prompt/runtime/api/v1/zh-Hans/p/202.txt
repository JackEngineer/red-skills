Motion Prompt #202

含义：在暗墙上用发光灯管勾出形状
示例内容：同一张线稿变成暗色砖墙上的发光霓虹灯管；房屋、树、太阳和山丘轮廓发亮并向四周泛光。
动效规格：
- 材料：暗色砖墙与发光霓虹灯管
- 外观：仅以灯管线条勾勒形状，光晕向周围扩散；示例使用红、黄、绿灯管
- 示例：将同一张基础草图（山丘上的房屋、树和太阳的线稿）作为参考交给图像模型，按此风格重绘。0.5 s 至 1.35 s，以斜向擦除从草图切换为该风格；画面缓慢放大至 1.045x，持续到 4.0 s；4.0 s 至 4.5 s 淡回草图（单次循环 = 4.7 s，cubic ease-in-out）
适用场景：适合夜间氛围，或店铺、酒吧招牌的效果。
