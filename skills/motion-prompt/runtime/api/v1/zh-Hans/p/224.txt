Motion Prompt #224

含义：以鱼骨的形状列出原因
示例内容：主骨向右延伸至鱼头（结果），斜骨从上下两侧接入主骨，每根斜骨上再生出小侧骨（原因）。
动效规格：
- 主骨：尾部出现后（0.35–0.6 s），一条从 x = 52 到 x = 404 的线（深灰、3 px、头部 14 px）在 0.45 s 至 1.0 s 延伸；鱼头为写有“结果”的 92×56 px 蓝框，在 0.95 s 弹性出现
- 斜骨：六根斜骨从主骨的 x = 150、258 和 366 处向左上和左下倾斜（横向 62 px，向上或向下 80 px，中蓝、3 px）；从 1.1 s 开始，每列间隔 0.14 s，各用 0.35 s 绘出，下方斜骨再晚 0.07 s
- 侧骨：每根斜骨的 36% 和 68% 处，向左延伸一条长 26 px 的水平线（灰色、2.5 px），紧随斜骨之后、间隔 0.08 s，各用 0.22 s 长出
- 结束：整个图形在 4.1 s 至 4.5 s 淡出，卡片保持空白，直到 4.7 s 循环重新开始
适用场景：适合按类别列出导致某个结果的可能原因。
