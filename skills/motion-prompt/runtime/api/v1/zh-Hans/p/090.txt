Motion Prompt #090

含义：图片接近视口时才开始加载
示例内容：灰色占位块滚入视口后，中央先出现旋转加载指示器，图片加载完成后淡入；第一行从开始就已加载。
动效规格：
- 3 × 3 网格，占位块为 151 × 92；第一行从开始就显示。滚动：0.35–1.1 s 从 0→110 px，1.7–2.5 s 从 110→225 px，3.5–4.5 s 从 225→0（三次方缓入缓出）。
- 占位块上边缘越过视口底部（168 px）时开始加载，每列比左侧一列延迟 0.12 s。
- 加载指示器在占位块中央旋转 0.45 s，半径 11，每 0.8 s 一圈。
- 随后图片在 0.35 s 内从 0→1 淡入（三次方缓出）。尚未加载的占位块显示图片图标。
- 从视口底部离开的占位块在不可见处重置。
适用场景：适合图片较多的页面，加快首屏加载。
