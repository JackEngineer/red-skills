请使用“青橙色调（英文名：Teal and orange）”，它属于“摄影效果、光线与风格”素材包。
Motion Prompt #117

含义：阴影偏青，肤色与高光偏橙
示例内容：同一片风景中的天空、山丘、地面和人物暗部转为青色，人物受光边缘和太阳转为橙色，形成互补色对比。
动效规格：
- 场景 3：左侧为半身像（头部中心 x 140、y 82，半径 28 px），右侧有山丘、房屋、树木和太阳（x 432、y 54，半径 15 px）。
- 青色：天空 #CFE6E3，山丘 #8CC1BE 和 #62A2A1，地面 #3F8083，树木 #2F6A6E，人物 #1D4E53。
- 橙色：人物亮部 #FF9248，太阳 #FF8236，太阳光环 #FFC48C。
- 时间：效果在 0.4 s 至 1.4 s 之间显现，保持至 4.0 s，并在 4.8 s 前消失（单次 = 5 s，三次缓入缓出，约为 cubic-bezier(0.65,0,0.35,1)）。
适用场景：适合色彩对比强烈的大片或预告片风格。
