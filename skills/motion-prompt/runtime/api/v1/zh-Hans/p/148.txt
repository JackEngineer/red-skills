Motion Prompt #148

含义：按区块切换页面背景色
示例内容：每次滚动进入新区块，整页背景依次从奶油色渐变为藏青色、浅蓝色；深色背景下文字变白。
动效规格：
- 视口 511 × 168，三个区块各高 168 px（一屏）。滚动：0.3–1.2 s 从 0→168 px，1.8–2.7 s 从 168→336，3.3–4.4 s 从 336→0（三次方缓入缓出）。一次演示 4.7 s，每个 9.4 s 素材包周期内重复两次。
- 背景色：清晨 #FFEBD9 → 夜晚 #1E2A4A → 假日 #DDE6FF。整页后方统一绘制一种颜色，经过区块边界时混合过渡。
- 混合进度：滚向下一区块的 5%–95% 之间从 0→1（二次方缓入缓出），由滚动位置驱动，而非时间。
- 进入夜晚时，标题从藏青色混合至白色，正文条块从米色变为蓝灰色；区块标签（01 清晨等）保持橙色。
- 各区块的图片（太阳、月亮与星星、山景照片）随页面移动。滚动条滑块随滚动移动。
适用场景：适合各章节氛围不同的叙事页面，或对比昼夜、四季等场景。
