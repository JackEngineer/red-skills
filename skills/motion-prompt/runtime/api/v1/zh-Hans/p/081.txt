请使用“悬停抬升（英文名：Hover lift）”，它属于“落地页与网页效果”素材包。
Motion Prompt #081

含义：悬停时元素抬高并加深阴影
示例内容：只有光标悬停的卡片略微抬起、阴影扩散；移开后恢复原位。
动效规格：
- 三张卡片（146 × 128，圆角 10）。光标从左到右在每张卡片上停留约 1 s。
- 悬停时，卡片在 0.3 s 内上移 10 px（三次方缓出）；离开时在同样的 0.3 s 内返回（类似 CSS transition）。
- 阴影与抬升同步变化：模糊 6→22 px，y 偏移 2→12 px，不透明度 0.08→0.22。
- 页面浅灰，卡片白色，便于看清阴影。
适用场景：适合让卡片和按钮显得可以点击。
