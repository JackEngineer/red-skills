Motion Prompt #212

含义：纸张折叠粘贴组成的立体模型
示例内容：同一张线稿变成彩色卡纸折成的模型照片：房屋是盒子，树和太阳是多面体，可见折痕、粘贴片和裁切边缘。
动效规格：
- 构造：按模板裁切彩色卡纸，再折叠粘合为 3D 模型
- 外观：清晰的折边、略微露出的小粘贴片和白色纸张裁切边；在桌面上从正面斜角拍摄的照片
- 注意：并非纯白浮雕，也不同于分层纸艺（#206）的平面叠层
- 示例：将同一张基础草图（山丘上的房屋、树和太阳的线稿）作为参考交给图像模型，按此风格重绘。0.5 s 至 1.35 s，以斜向擦除从草图切换为该风格；画面缓慢放大至 1.045x，持续到 4.0 s；4.0 s 至 4.5 s 淡回草图（单次循环 = 4.7 s，cubic ease-in-out）
适用场景：适合手工感的 3D 产品图片，或展示手工制作和教学材料。
