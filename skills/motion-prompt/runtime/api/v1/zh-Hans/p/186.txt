Motion Prompt #186

含义：平滑衔接相同构图的两段画面
示例内容：同一人物的两次拍摄通过位置和姿势的平滑插值连接，不会像跳切那样产生突变。
动效规格：
- 拍摄 1（0–2.0 s）：相机固定（高度 1.45 m）；人物位于左侧 0.4 m、距离 3.3 m，手臂和腿角度为 -0.45 rad。拍摄 2（从 2.45 s 起）：右侧 0.35 m，+0.55 rad。两者都按 0.12·sin(t×3) rad 轻微摆动。
- 形变（2.0–2.45 s，0.45 s）：位置采用二次缓入缓出插值（约为 cubic-bezier(0.45,0,0.55,1)），两种姿势绘制在相同的插值位置并交叉淡化。
- 仅在形变期间，整幅画面应用 sin(q×π)×2.2 px 的模糊以柔化衔接（#041 跳切允许位置突变）。
- 底部条带：拍摄 1（灰色）、形变（蓝色窄段）、拍摄 2（灰色），带播放头。
- 返回：最后 0.5 s 交叉淡化回拍摄 1 的起点；右上角读数为“拍摄 1” → “变形” → “拍摄 2”。
适用场景：适合精简访谈或旁白，或在不引人注意的情况下去掉口误。
