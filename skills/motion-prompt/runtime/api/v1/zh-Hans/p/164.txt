Motion Prompt #164

含义：显示距截止时间的剩余时间并递减
示例内容：“距离活动结束”下方的时、分、秒逐秒倒计时；只有变化的数字向上滑出，新数字从下方进入。
动效规格：
- 视口 511 × 168：橙色渐变条中显示“距离活动结束”和六个时、分、秒数字块，各为 34 × 50、圆角 6、数字 32 px。仅此卡片每 9.4 s（素材包周期）运行一次。
- 从 02:15:04 开始，自 0.4 s 起每隔 1 s 减少一秒，共九次，结束于 02:14:55。4.4 s 时，02:15:00 → 02:14:59 触发分钟变化。
- 仅数字变化的块播放动画：在 0.32 s 内（三次方缓入缓出），旧数字向上滑出，新数字从下方滑入，裁切在块内。
- 9.4 s 时直接切回 02:15:04。
适用场景：适合限时优惠或申请截止日期，清楚显示剩余时间。
