Motion Prompt #058

含义：横向滑动切换展示项
示例内容：每次点击右箭头，三个不同图像组成的一行向左滑动一格，下方圆点随之切换。
动效规格：
- 542×191 卡片，循环周期 4.5 s。幻灯片 330×138、圆角 8，居中排列，间隔 18 px；两侧露出相邻项的一部分。
- 左右为带箭头的白色圆按钮（半径 18，阴影模糊 10）；下方三个圆点，当前项为蓝色 16×8，其他为 8×8。
- 光标在 1.0、2.1、3.2 s 点击右箭头 (514, 88)。
- 每次点击以 easeInOutCubic 在 0.4 s 内将整行向左移动 348 px（一张图加间隔）。
- 三幅图（风景、三个圆、柱状图）重复排列，移动三次后回到第一幅。
适用场景：适合在有限空间中逐一展示多张图片或推荐内容。
