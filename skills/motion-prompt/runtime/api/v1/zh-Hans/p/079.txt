请使用“滚动进度条（英文名：Scroll progress bar）”，它属于“落地页与网页效果”素材包。
Motion Prompt #079

含义：顶部条显示阅读进度
示例内容：逐段阅读文章时，顶部细线从左向右增长，到达页面底部时铺满整条。
动效规格：
- 文章分四次、每次 110 px，从 0→430 px 滚动；每次移动 0.45 s，停顿 0.4 s（三次方缓入缓出）。
- 3.75–4.55 s 从 430→0 返回。
- 视口顶部有高 6 px 的进度条，浅灰轨道、橙色填充。
- 填充宽度 = 511 px × scroll / 430，即滚动进度本身（与 CSS animation-timeline: scroll() 一致）。
适用场景：适合长文章，显示还有多少内容未读。
