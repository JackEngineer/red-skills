Motion Prompt #136

含义：手绘线条逐帧轻微抖动
示例内容：手绘线稿每隔几帧轻微抖动，画面内容本身保持不动。
动效规格：
- 静止线稿包含黄色星形、白云、薄荷绿闪光线和浅色地面线，线宽 6–8，圆形端点。
- 图案本身不动。每 4.7 s 重绘 47 次，约每 0.1 s 一次，每个点在 x 和 y 方向使用最大 ±3.5 px 的固定随机偏移。
- 先将每条线变成点列，间距 6–13 px，云轮廓共 96 点，再通过相邻点的中点绘制二次曲线，形成手绘逐帧抖动感。
- 偏移由帧编号和点编号的哈希决定，因此同一帧的外观始终相同。
适用场景：适合手绘插画、图标或文字，让静止图像也保有手绘质感。
