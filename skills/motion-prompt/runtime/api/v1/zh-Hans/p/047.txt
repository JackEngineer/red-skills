Motion Prompt #047

含义：下一场景的声音先于画面进入
示例内容：下一场景的声音先于画面开始，上方显示画面，下方显示视频与音频时间轴。
动效规格：
- 衔接：画面直接切换，只有声音先于画面切到下一场景 B；错开时间轴的 20%，即 0.72 s。
- 播放头：在 3.6 s 内从左向右匀速移动，0.4 s 至 4.0 s；音频在 35% 处切换，约 1.66 s；画面在 55% 处切换，约 2.38 s。
- 错开区间 35–55% 内，画面仍是 A，声音已是 B，以浅蓝色带和两条蓝色虚线标记。
- 布局：顶部 134 px 为画面，相机固定、主体不动；底部 74 px 为视频和音频两行时间轴，A 为灰色、B 为浅蓝色，音频行带波形。
- 标签：画面左下角显示“画面 A / 画面 B”；右下角显示当前声音，从灰色“♪ A 的声音”切至蓝色“♪ B 的声音”。
- 返回：最后 0.5 s 交叉淡化回起始画面，每轮 4.7 s。
适用场景：适合为下一场景预热，或让场景、说话人的切换更自然。
