请使用“点彩画（英文名：Pointillism）”，它属于“图像生成常用的画风名称”素材包。
Motion Prompt #197

含义：用一个个小色点排列成画
示例内容：同一张线稿变成完全由色点组成的画面；天空、房屋、树和地面都由清晰可见、较大的色点构成。
动效规格：
- 技法：仅将色点并排铺放，不使用线条或整片填色
- 色点大小：在小卡片上仍应清晰可见（过小的点会看起来像水彩）
- 示例：将同一张基础草图（山丘上的房屋、树和太阳的线稿）作为参考交给图像模型，按此风格重绘。0.5 s 至 1.35 s，以斜向擦除从草图切换为该风格；画面缓慢放大至 1.045x，持续到 4.0 s；4.0 s 至 4.5 s 淡回草图（单次循环 = 4.7 s，cubic ease-in-out）
适用场景：适合明亮、带有手工感和节奏感纹理的画面。
