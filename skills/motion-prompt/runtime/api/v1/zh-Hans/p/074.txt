请使用“滚动淡入（英文名：Fade-in on scroll）”，它属于“落地页与网页效果”素材包。
Motion Prompt #074

含义：元素进入视口时逐渐出现
示例内容：页面滚动时，标题、卡片和正文进入视口后，分别上移到位并淡入。
动效规格：
- 滚动：0.35–1.0 s 从 0→95 px，1.5–2.1 s 从 95→200 px，3.2–4.4 s 从 200→0（均为三次方缓入缓出）。
- 触发线位于视口高度的 85%（距顶部 143 px）。元素上边缘越过触发线时启动动画，与 Intersection Observer 的思路一致。
- 触发后，在 0.7 s 内，不透明度 0→1，下方偏移 28 px → 0（三次方缓出）。
- 三个元素分别为标题（距页面顶部 172 px）、三张卡片组成的一行（206 px）和正文（334 px），起初均位于视口下方。同一行的卡片同时出现。
- 向上返回时，元素从视口底部离开后在不可见处重置，下次再次播放。
适用场景：适合较长的落地页，让内容随阅读滚动逐步出现。
