请使用“淡出到黑场（英文名：Fade to black）”，它属于“镜头运动与转场（第 2 弹）”素材包。
Motion Prompt #187

含义：画面逐渐变暗直至全黑
示例内容：整幅画面逐渐变黑，下一场景再从黑色中亮起。
动效规格：
- 淡出：1.4 s 至 2.6 s（1.2 s），在离场画面上叠加黑色（rgb(20,20,24)），不透明度 0 → 100%，二次缓入缓出（约为 cubic-bezier(0.45,0,0.55,1)）。
- 全黑：2.6 s 至 3.1 s 完全黑屏；2.9 s 时通过硬切换入下一画面，切换不可见。
- 淡入：3.1 s 至 4.3 s（1.2 s），黑色不透明度按相同缓动从 100% → 0。
- 相机：两幅画面中均固定（A 高度 1.4 m；B 高度 1.6 m、俯仰角 +0.1 rad）；主体也不移动。
- 每 4.7 s 交替 A→B 和 B→A（往返 9.4 s）；右上角读数为“淡出” / “淡入”；取景器标记在黑屏上方保持可见。
适用场景：适合章节间隔、较长时间流逝或故事结尾。
