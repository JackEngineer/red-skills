Motion Prompt #106

含义：通过选择性模糊让实景像微缩模型
示例内容：街景的上下区域变模糊，只有中间包含道路、汽车和小人物的条带保持清晰，让街道看起来像模型。
动效规格：
- 街角（建筑、树木和路灯位于 y 132–162 的道路后方），不含较大的人物；四名身高 23–26 px 的小人物站在人行道上（脚部位于 y 172）；汽车每 5 s 从 x −60 行驶到 600。
- 清晰区域：y 66–176 保持清晰。
- 模糊：y 0–42 和 y 190–208 从 0 → 7 px；y 42–66 和 y 176–190 从 0 → 3 px。
- 条带边缘有虚线（线段 6 px，间隔 5 px，#8E8E93，不透明度 75%）。
- 时间：效果在 0.4 s 至 1.4 s 之间显现，保持至 4.0 s，并在 4.8 s 前消失（单次 = 5 s，三次缓入缓出，约为 cubic-bezier(0.65,0,0.35,1)）。
适用场景：适合把城市或活动现场呈现为玩具模型世界。
