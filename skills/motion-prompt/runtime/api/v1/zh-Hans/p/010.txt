Motion Prompt #010

含义：越过目标后回到目标位置并停稳
示例内容：仪表指针摆过目标位置，再回摆并稳定下来。
动效规格：
- 每轮 4.7 s。半圆仪表（半径 128，描边 26），目标位于整个弧长的 0.7 处（从左端起 126°）。
- 从 0.25 s 开始，数值 = 0.7 × (1 − e^(−4.6t)·cos(10.5t))。约 0.3 s 后超出目标约 25%，随后振荡并停在目标处。
- 超出目标的部分以珊瑚色绘制，黄色刻度标记目标。
- 填充圆弧为蓝色至薄荷绿渐变，指针为白色，宽 9。
- 返回：从 3.7 s 开始，数值 = 0.7 × e^(−7.5t)·cos(8.5t)，回到 0（停止前略低于 0）。
适用场景：适合让入场元素显得有活力、有弹性。
