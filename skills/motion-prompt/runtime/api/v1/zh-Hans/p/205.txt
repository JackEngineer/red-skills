请使用“Risograph 孔版印刷（英文名：Risograph print）”，它属于“图像生成常用的画风名称”素材包。
Motion Prompt #205

含义：两三种油墨略微错位叠印
示例内容：同一张线稿变成黄色和蓝绿色两色油墨的印刷品；两层油墨略有套印错位，油墨颗粒和纸张纹理清晰可见。
动效规格：
- 媒介：使用两种或三种油墨的孔版印刷（Risograph）
- 外观：突出各层之间的套印错位、油墨颗粒和纸张纹理；示例使用黄色和蓝绿色
- 注意：两种颜色平滑混合会看起来像双色调（#116）；应保留错位和颗粒
- 示例：将同一张基础草图（山丘上的房屋、树和太阳的线稿）作为参考交给图像模型，按此风格重绘。0.5 s 至 1.35 s，以斜向擦除从草图切换为该风格；画面缓慢放大至 1.045x，持续到 4.0 s；4.0 s 至 4.5 s 淡回草图（单次循环 = 4.7 s，cubic ease-in-out）
适用场景：适合独立小刊、传单和独立海报的质感。
