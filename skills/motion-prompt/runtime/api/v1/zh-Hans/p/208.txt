请使用“线稿（英文名：Line art）”，它属于“图像生成常用的画风名称”素材包。
Motion Prompt #208

含义：只用单色线条，不上色
示例内容：同一张线稿变成奶油色纸上用单支深海军蓝色笔绘制的精细线描，每块屋瓦、每片叶子、每根草和每束太阳光都用线条描出。
动效规格：
- 媒介：奶油色纸上使用单支深海军蓝色笔
- 外观：仅用细线，描出全部细节，线条粗细有变化
- 避免：色块填充和明暗铺色
- 示例：将同一张基础草图（山丘上的房屋、树和太阳的线稿）作为参考交给图像模型，按此风格重绘。0.5 s 至 1.35 s，以斜向擦除从草图切换为该风格；画面缓慢放大至 1.045x，持续到 4.0 s；4.0 s 至 4.5 s 淡回草图（单次循环 = 4.7 s，cubic ease-in-out）
适用场景：适合需要展示线条之美的涂色页、野外图鉴或包装。
