Motion Prompt #084

含义：按钮向附近光标偏移
示例内容：光标靠近时，按钮被吸引过去并跟随；光标离开后，按钮轻晃着回到原位。
动效规格：
- 中央按钮为 168 × 52，橙色，圆角 26。吸引范围为距按钮中心半径 110 px 内。
- 范围内：目标偏移 = (cursor − button centre) × 0.35；每帧（60 fps）按钮向目标移动剩余距离的 18%。
- 离开范围后，以 elastic.out(1, 0.3) 在 1.1 s 内从当前偏移回到 0：2^(−10x)·sin((x − 0.075)·2π/0.3) + 1。
- 光标从左侧进入，绕按钮一圈，然后向右离开。
适用场景：适合最希望用户点击的单个按钮，例如注册或联系。
