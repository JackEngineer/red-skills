Motion Prompt #023

含义：画面像发生故障一样错位和分色
示例内容：文字切片横向错位、颜色分离，小色条出现，但不发生亮度闪烁。
动效规格：
- 白色粗体文字，104 px。每 4.7 s 发生两次故障效果：0.55–1.25 s（5 步）和 2.9–3.74 s（6 步），其余时间静止。
- 每步持续 0.14 s，显示一种固定扰动，以跳变方式呈现，不进行平滑动画。
- 色彩分离：珊瑚色副本左移 7–16 px、下移 2 px；青色（#22D3EE）副本同幅度右移、上移 2 px；白色文字绘制在最上方。
- 切片错位：2–4 条水平条带（高 10–35 px，y 40–150）向左或向右位移 18–64 px。
- 三个小色条（珊瑚色、青色、黄色，宽 30–120 × 高 5–12）出现在随机位置。
- 背景亮度始终不变，没有全屏闪烁；随机值使用固定种子。
适用场景：适合在标题或转场中点缀数字感、错误感或不安氛围。
