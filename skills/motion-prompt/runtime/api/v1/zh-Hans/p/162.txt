Motion Prompt #162

含义：点击图片后在变暗的背景上放大
示例内容：点击图库缩略图后，页面变暗，照片在中央放大显示；点击 ×，照片缩回原缩略图。
动效规格：
- 视口 511 × 168，四张缩略图为 108 × 72、圆角 6。0.75 s 点击第三张，3.0 s 点击右上角 ×。一次演示 4.7 s，每个 9.4 s 素材包周期内重复两次。
- 打开：0.85–1.3 s（0.45 s，三次方缓出）深色遮罩（rgb(14,18,28)，不透明度 0 → 0.82）覆盖页面，被点击的缩略图放大至中央的 261 × 128。
- 打开过程的后半段，照片下方出现“3 / 4”，两侧出现上一张、下一张箭头，右上角出现 ×。
- 关闭：3.05–3.4 s（0.35 s，三次方缓入缓出）反向执行相同运动，照片返回缩略图。
适用场景：适合需要在当前页放大查看的案例、作品集或商品照片。
