Motion Prompt #018

含义：图形覆盖画面后揭示下一场景
示例内容：彩色条带扫过并覆盖画面，离开时露出下一个场景。
动效规格：
- 白天 → 夜晚 → 白天，每段 2.35 s。四条水平条带（高 52，蓝色、珊瑚色、黄色、薄荷绿），端部倾斜 80 px。
- 覆盖：0.38–1.0 s。每条带的前缘从画面一侧移动到另一侧；各条带依次延迟阶段时长的 14%，并在阶段时长的 58% 内使用三次方缓入缓出。
- 1.0 s 完全覆盖画面时，底下的场景切换为下一场景。
- 揭开：1.12–1.75 s。每条带的后缘以相同延迟和曲线跟随，露出下一场景。
- 方向：白天→夜晚从左到右，夜晚→白天镜像反向。
适用场景：适合用品牌色形状切换场景，例如章节分隔或话题切换。
