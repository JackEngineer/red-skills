Motion Prompt #065

含义：三横线图标点击后展开菜单
示例内容：点击页头右侧的三横线图标，图标变成 ×，菜单从页头下方落下；再次点击关闭。
动效规格：
- 542×191 卡片，循环周期 4.5 s。白色页头高 44；右侧 (500, 22) 处有三条横线，长 24、粗 3、间距 8 px。
- 光标在 1.0 s 和 3.3 s 点击。展开量 a：1.0–1.3 s 从 0→1，3.3–3.6 s 从 1→0，使用 easeInOutCubic。
- 横线变 ×：上、下横线向中央移动 8 px，旋转 ±45°；中线以不透明度 1 − a 淡出。展开时为蓝色。
- 菜单：白色，高 140，上边缘 y = 44 − 140 + 140·a，从页头下方落下（裁切在页头以下）；阴影模糊 16，四个菜单项，第一项蓝色。
适用场景：适合窄屏页面，将主导航收在一个按钮内。
