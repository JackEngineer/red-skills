Motion Prompt #177

含义：从低处向上拍
示例内容：相机降到接近地面并向上仰拍，人物显得高大，建筑显得耸立。
动效规格：
- 相机：从 1.5 m 降至 0.35 m，同时俯仰角 0 → +0.32 rad（向上约 18°）；不前后移动。
- 时间：0.6 s 至 2.2 s（1.6 s），三次缓入缓出（约为 cubic-bezier(0.65,0,0.35,1)）。
- 主体：人物静止站在前方 4.5 m；一座高 11.8 m 的塔位于左侧 3 m、距离 22 m 处。相机向上看时，人物和塔向上延伸，地平线下降。
- 保持：2.2 s 至 4.2 s 保持低角度（留出观看构图本身的时间）。
- 返回：最后 0.5 s 交叉淡化回平视高度（单次 = 4.7 s）；右上角读数显示角度和高度（↗ 0° · 1.5m → ↗ 18° · 0.4m）。
适用场景：适合让人物显得有力量或高大，或强调建筑高度。
