请使用“抽屉面板（英文名：Drawer (Off-canvas)）”，它属于“UI 组件”素材包。
Motion Prompt #050

含义：从屏幕侧边滑出的面板
示例内容：点击“菜单”后，高面板从左侧滑入；点击面板外侧后滑回。
动效规格：
- 542×191 卡片，循环周期 4.5 s。光标在 1.0 s 点击“菜单”按钮（110×34，左上角）。
- 展开量 a：1.0–1.38 s 以 easeOutCubic 从 0→1。整卡遮罩为 rgba(18,20,28)，不透明度 0.36·a。
- 面板：白色，宽 210，高度与卡片相同，x = −210 + 210·a，从左边缘滑入。阴影模糊 22，alpha 0.25。
- 顶部为头像（半径 14）和姓名，下方四行菜单间距 32 px；第一行以浅蓝色条带表示选中。
- 关闭：光标在 3.3 s 点击面板外的 (420, 120)；a 乘以 (1 − easeInOutCubic，作用于 3.3–3.65 s)，面板滑回。
适用场景：适合将导航或筛选项收在屏幕外，需要时再展开，尤其适用于移动端。
