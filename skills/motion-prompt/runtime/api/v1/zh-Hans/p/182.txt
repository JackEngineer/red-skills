请使用“深焦镜头（英文名：Deep focus）”，它属于“镜头运动与转场（第 2 弹）”素材包。
Motion Prompt #182

含义：从近处到远处全部清晰
示例内容：从前方的花朵到后方的人物与建筑，所有物体同时变得清晰。
动效规格：
- 相机：位置、方向和焦距全部固定（高度 1.1 m）；只有模糊程度变化。
- 模糊：前景花朵（左侧 0.75 m，距离 2 m）从 5 px → 0 px，背景（人物在右侧 0.9 m、距离 9 m；建筑；山脉）从 6 px → 0 px，两者同时变清晰（#033 焦点转移会模糊其中一侧）。
- 时间：0.5 s 至 3.4 s（2.9 s），三次缓入缓出（约为 cubic-bezier(0.65,0,0.35,1)）。
- 对焦标记：花朵（半宽 46 px）和人物（半宽 30 px）周围都有蓝色直角框，合焦时不透明度 0 → 1。
- 返回：在 3.4–4.2 s 保持，最后 0.5 s 交叉淡化回起点；右上角读数显示光圈（f/1.8 → f/16）。
适用场景：适合让观众自由观看画面各处，或同时展示不同纵深位置发生的事情。
