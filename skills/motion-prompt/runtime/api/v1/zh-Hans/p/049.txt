Motion Prompt #049

含义：打开浮窗并暂时阻止操作背景
示例内容：点击“打开”后，整页变暗，一个小窗口略微放大并出现在中央；点击 × 关闭。
动效规格：
- 542×191 卡片，循环周期 4.5 s。光标在 0.95 s 到达“打开”按钮（120×36，左下角），在 1.0 s 点击。
- 展开量 a：1.0–1.32 s 以 easeOutCubic 从 0→1。覆盖整张卡片的遮罩为 rgba(18,20,28)，不透明度 0.42·a。
- 窗口：白色，280×140，圆角 12，中心位于 (271, 97)，阴影模糊 24、y 偏移 8、alpha 0.25。缩放为 0.9 + 0.1·a，不透明度为 a。
- 内部包含粗体标题栏、两行文字、右下角蓝色 88×30 按钮和右上角 ×。
- 关闭：光标在 3.0 s 前移至 ×，3.3 s 点击；a 乘以 (1 − easeInOutCubic，作用于 3.3–3.58 s)。
适用场景：适合需要用户暂停当前操作、专注处理一件事的场景，例如确认操作或填写简短表单。
