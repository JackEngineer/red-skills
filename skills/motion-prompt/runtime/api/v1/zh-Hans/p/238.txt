Motion Prompt #238

含义：按负责人分泳道排列步骤
示例内容：左侧标出三条泳道的名称：客户、销售和制作；步骤框在不同泳道中依次出现，以折线箭头连接。
动效规格：
- 泳道：三条高 60 px 的白色泳道，左侧 62 px 宽的列中显示灰色泳道名称（18 px），整个循环中保留
- 方框：五个 56×30 px 的圆角框，从 x = 138 到 474，依次位于客户 → 销售 → 制作 → 销售 → 客户泳道；从 0.4 s 开始，间隔 0.38 s，各用 0.28 s 弹性出现（ease-out-back）；最后一个为深蓝色
- 箭头：从前一个方框右边缘出发，先水平延伸再向上或向下接入下一个方框（深灰、2.5 px、头部 9 px），从各方框出现前 0.24 s 开始，用 0.26 s 生长
- 区别于 #233 甘特图：没有日期刻度；通过泳道名称和跨泳道箭头表达流程
- 结束：整个图形在 4.1 s 至 4.5 s 淡出，卡片保持空白，直到 4.7 s 循环重新开始
适用场景：适合展示多人或多团队共同流程中，由谁在何时执行哪项工作。
