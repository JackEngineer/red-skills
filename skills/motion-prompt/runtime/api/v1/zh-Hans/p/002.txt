Motion Prompt #002

含义：多个元素错开时间依次出现
示例内容：图表中的柱条从左向右依次升起，每根略微延迟。
动效规格：
- 每轮 2.35 s。七根柱条（宽 44，间距 20，高度 52, 84, 68, 112, 92, 136, 158），颜色依次循环使用蓝色、珊瑚色、黄色、薄荷绿。
- 第 i 根柱条（从 0 编号）在 0.15 + 0.12·i s 开始，以基线为锚点，在 0.5 s 内通过 backOut (s = 2.6) 从 0 增长至完整高度，略微超出后回稳。
- 白点（半径 6.5，位于柱顶上方 16 px）：比对应柱条晚 0.34 s 开始，使用弹簧曲线 1 − e^(−7t)·cos(16t)。
- 退场：柱条从 1.78 + 0.045·i s 开始，以三次方缓入在 0.26 s 内缩小；白点先消失，从 1.70 + 0.045·i s 开始，历时 0.2 s。
适用场景：适合让列表行、图表柱条、卡片等多个项目依次出现，引导视线逐项移动。
