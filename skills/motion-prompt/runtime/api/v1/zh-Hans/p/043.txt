Motion Prompt #043

含义：快速横摇形成模糊并切入下一镜头
示例内容：相机快速横向甩动，在条纹状模糊最强时切入下一场景。
动效规格：
- 衔接：1.7 s 至 2.5 s，历时 0.8 s；前 0.4 s 甩走前镜头，后 0.4 s 甩入后镜头并停稳。
- 前半段：前镜头偏航角 0 → +0.45 rad，约 26°，二次方缓入缓出；后半段：后镜头偏航角 -0.45 rad → 0，缓动相同。
- 切换：在 50% 处直接替换，此时模糊最强，将切换隐藏。
- 模糊：对分布在 ±1.6 帧范围内的 9 次渲染取平均，帧率 30 fps。
- 相机：高 1.4 m，除甩动阶段外固定；主体均不动，A 为人物，B 为汽车和城市。
- 每 4.7 s 在 A→B 和 B→A 间交替，往返 9.4 s；右上角显示“A → B” / “B → A”。
适用场景：适合在保持活力的同时切换地点或话题。
