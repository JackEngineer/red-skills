请使用“刺绣（英文名：Embroidery）”，它属于“图像生成常用的画风名称”素材包。
Motion Prompt #214

含义：用彩线在布上绣出图案
示例内容：同一张线稿变成布料上的彩线刺绣，针脚和布料织纹清晰可见。
动效规格：
- 材料：布料与彩色绣线
- 外观：每个针脚的方向和布料织纹均清晰可见
- 示例：将同一张基础草图（山丘上的房屋、树和太阳的线稿）作为参考交给图像模型，按此风格重绘。0.5 s 至 1.35 s，以斜向擦除从草图切换为该风格；画面缓慢放大至 1.045x，持续到 4.0 s；4.0 s 至 4.5 s 淡回草图（单次循环 = 4.7 s，cubic ease-in-out）
适用场景：适合需要温暖手工质感的周边商品、包装或节日贺卡。
