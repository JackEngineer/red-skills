Motion Prompt #028

含义：相机不动，通过镜头变焦放大
示例内容：相机保持不动，只有焦距变长，整幅画面按相同比例放大。
动效规格：
- 相机：位置与方向固定，高 1.5 m；只改变焦距，从 330 px → 1200 px，显示为 24mm → 87mm，约 3.6 倍。
- 指数插值：f = 330 × (8/2.2)^p，其中 p 在 0.5 s 至 3.4 s（2.9 s）内使用三次方缓入缓出。
- 主体：人物静止站在前方 8 m，最终尺寸与 03 推镜头 相同，约 3.6 倍。
- 无视差：前景立柱与岩石、人物、建筑和山按相同比例缩放，遮挡关系不变。
- 返回：在 3.4–4.2 s 保持，最后 0.5 s 交叉淡化回起始画面，每轮 4.7 s。
- 右上角以 mm 显示焦距，24mm → 87mm。
适用场景：适合不移动相机就将注意力集中到一点；比推轨前进更平面，也更像旁观视角。
