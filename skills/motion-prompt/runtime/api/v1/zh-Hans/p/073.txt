Motion Prompt #073

含义：滚动时背景层比内容移动得慢
示例内容：页面向下滚动时，标题正常上移，天空与太阳、远山和近山则以较慢速度移动。
动效规格：
- 浏览器窗口的视口为 511 × 168。滚动：0.3–1.9 s 从 0→120 px，2.9–4.3 s 从 120→0（三次方缓入缓出）。
- 各图层的位移为滚动量 × 系数：天空与太阳 0.15，远山 0.4，近山 0.7。
- 标题（28 px）、按钮和下一区块按 1.0 移动（正常滚动）。
- 下一区块为白色，从首屏底部（168 px）开始，滑过移动较慢的背景。
- 右侧滚动条滑块随滚动移动。
适用场景：适合为首屏或区块照片增加纵深感。
