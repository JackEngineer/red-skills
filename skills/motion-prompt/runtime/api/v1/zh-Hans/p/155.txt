Motion Prompt #155

含义：悬停时换成另一张照片
示例内容：光标悬停于商品卡片时，T 恤正面照片交叉淡化为背面；光标离开后返回正面。
动效规格：
- 视口 511 × 168，含两张商品卡片，照片框 196 × 112、圆角 8，下方为名称和价格。光标先停左侧、再停右侧，各约 1.3 s。一次演示 4.7 s，每个 9.4 s 素材包周期内重复两次。
- 悬停时，正面照片（胸前小圆点）在 0.3 s 内交叉淡化为背面照片（背后大星形），使用二次方缓入缓出；离开时用相同的 0.3 s 淡回。
- 照片下方两个圆点（半径 3）表示正在显示哪张照片，深色圆点代表当前项。
- 悬停区域覆盖整张卡片，包括名称。外框、名称和价格均不移动。
适用场景：适合电商商品网格，无需离开列表即可查看其他角度或模特上身图。
