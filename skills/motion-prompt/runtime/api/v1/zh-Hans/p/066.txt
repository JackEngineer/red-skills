Motion Prompt #066

含义：显示页面层级位置的链接路径
示例内容：点击面包屑中的“课程”可返回列表页；点击列表卡片后回到详情页。
动效规格：
- 542×191 卡片，循环周期 4.5 s。顶部显示“首页 › 课程 › 网页制作”（17 px），链接蓝色，当前页黑色加粗；y 46 处有分隔线。
- 光标悬停于“课程”（0.9–1.2 s 显示下划线），并在 1.0 s 点击。
- 返回上级的进度：1.0–1.25 s 以 easeInOutCubic 从 0→1。“› 网页制作”淡出，“课程”变为当前页（黑色加粗）。
- 内容从详情页（标题和文字）交叉淡化为三张卡片的列表（158×118，带风景图）。
- 返回详情：光标移至第一张卡片（2.45–2.8 s 显示蓝色描边），在 2.7 s 点击；详情页在 2.7–2.95 s 恢复。
适用场景：适合层级较深的网站，展示当前位置并提供返回上级的入口。
