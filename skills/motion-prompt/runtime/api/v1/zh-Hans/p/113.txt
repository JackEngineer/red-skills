Motion Prompt #113

含义：整体明亮、接近白色且阴影很浅
示例内容：同一片风景和人物变成接近白色的浅色，阴影很淡；右下方直方图的峰值向右端移动。
动效规格：
- 场景 3：左侧为半身像（头部中心 x 140、y 82，半径 28 px），右侧有山丘、房屋、树木和太阳（x 432、y 54，半径 15 px）。
- 颜色：天空 #FAF9F7 → #FFFFFF，山丘 #EAEDF1 → #F5F6F8，人物 #4D5A75 → #B9C0CE，阴影 #33405A → #A6AEBF，太阳 #F5A524 → #FFD889。
- 直方图（96×46 px，20 根柱）：峰值中心 0.56 → 0.85，宽度 0.2 → 0.09。
- 时间：效果在 0.4 s 至 1.4 s 之间显现，保持至 4.0 s，并在 4.8 s 前消失（单次 = 5 s，三次缓入缓出，约为 cubic-bezier(0.65,0,0.35,1)）。
适用场景：适合干净、明亮、柔和的产品照和人像。
