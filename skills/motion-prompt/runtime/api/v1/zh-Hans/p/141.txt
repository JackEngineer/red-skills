Motion Prompt #141

含义：马赛克逐渐变粗后切换画面
示例内容：画面逐渐变成更粗的像素块，在最粗处切换，再重新变清晰。
动效规格：
- 田野 → 城市 → 田野，每段 2.35 s。在 0.2–1.9 s（1.7 s），色块尺寸依次经过 1, 2, 3, 4, 6, 8, 11, 15, 20, 27, 36 px 后再缩小，中点 1.05 s 最粗。
- 前半段显示原场景，后半段显示新场景，在最大色块处替换。
- 方法：开启平滑，将画面缩至原宽度 ÷ 色块尺寸，再关闭平滑放大回原尺寸。
适用场景：适合游戏、复古或数字风格的转场，也可在切换时将内容模糊成色块。
