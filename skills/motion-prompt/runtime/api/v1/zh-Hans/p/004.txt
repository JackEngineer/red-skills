请使用“线条描绘（英文名：Line draw）”，它属于“动态图形”素材包。
Motion Prompt #004

含义：线条像被画出来一样逐渐延伸
示例内容：图表折线逐渐绘出，随后从起点一端逐渐擦除。
动效规格：
- 每轮 4.7 s。采用路径修剪方式绘制，动画控制每条笔画可见范围的起止比例。
- 坐标轴（L 形，宽 6）在 0.08–0.7 s 绘出；折线（薄荷绿，宽 11，穿过 7 个点的平滑曲线，圆形端点）在 0.4–1.95 s 绘出。两者均使用三次方缓入缓出。
- 绘制时，黄色圆点（半径 12，白色中心半径 5）沿前端移动。
- 箭头在 1.9–2.2 s 通过 backOut (s = 2.5) 张开，箭翼长 26、宽 20。
- 珊瑚色圆圈（半径 26，线宽 7）在 2.2–2.8 s 从顶部顺时针绘出，圈住一个峰值。
- 擦除：圆圈 3.5–4.0 s，折线 3.65–4.45 s，坐标轴 3.85–4.55 s，均从起点一端缩短。箭头在 4.3–4.45 s 淡出。
适用场景：适合强调笔画本身的场景，例如图表、路线、下划线和手绘圆圈。
