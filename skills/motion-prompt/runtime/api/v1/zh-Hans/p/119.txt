Motion Prompt #119

含义：红橙色光像漏入胶片一样侵入画面
示例内容：同一片风景的右边缘渗入一条漏光带，内侧为浅黄色，边缘为红色，缓慢摇摆。
动效规格：
- 场景 3：左侧为半身像（头部中心 x 140、y 82，半径 28 px），右侧有山丘、房屋、树木和太阳（x 432、y 54，半径 15 px）。
- 形状：四个高椭圆，中心位于画面右边缘外 30 px（循环中摇摆 ±6 px），纵向半径为画面高度的 1.1×。
- 横向半径及颜色：250 px #FFD089、不透明度 35%，170 px #FF9A3D、40%，95 px #FF5A3A、45%，45 px #FF3B30、50%（各自从 0 增长到此半径）。
- 时间：效果在 0.4 s 至 1.4 s 之间显现，保持至 4.0 s，并在 4.8 s 前消失（单次 = 5 s，三次缓入缓出，约为 cubic-bezier(0.65,0,0.35,1)）。
适用场景：适合怀旧、夏日、带有偶然感的回忆画面。
