Motion Prompt #036

含义：倾斜相机，使地平线呈对角线
示例内容：水平相机绕镜头轴滚转，使地平线倾斜，并保持这一构图。
动效规格：
- 相机：位置固定，高 1.5 m；仅滚转，0 → 0.36 rad，约 21°，整幅画面绕中心旋转。
- 时间：0.6 s 至 2.2 s，历时 1.6 s，使用三次方缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
- 主体：人物静止站在前方 7 m，地平线、建筑和人物以相同角度倾斜。
- 停留：2.2 s 至 4.2 s 保持倾斜，留出观看倾斜构图本身的时间。
- 返回：最后 0.5 s 交叉淡化回水平的起始画面，每轮 4.7 s。
- 右上角显示角度，∠ 0° → ∠ 21°。
适用场景：适合表达不安、紧张或情况不对劲的感觉。
