Motion Prompt #088

含义：访客准备离开时出现的弹窗
示例内容：光标从页面上方向标签栏和关闭按钮移出时，页面变暗并弹出“请稍等！”窗口；点击 × 关闭。
动效规格：
- 光标在 0.7–1.25 s 从页面向浏览器地址栏上移（三次方缓入缓出）。
- 光标越过视口顶边时触发（y = 0，约 1.07 s），与 document 上 mouseleave 且 clientY ≤ 0 的判断相同。
- 触发后 0.05–0.45 s 展开（三次方缓出）：藏青色背景遮罩不透明度 0→0.5；弹窗（260 × 132，圆角 12）不透明度 0→1，缩放 0.9→1。
- 内部包含标题、橙色优惠说明、优惠券按钮和右上角 ×。
- 2.9 s 点击 ×；在此后 0.03–0.25 s 消失（线性）。
适用场景：适合向即将离开、尚未完成转化的访客提供最后一次优惠。
