请使用“水墨画（英文名：Ink wash painting (sumi-e)）”，它属于“图像生成常用的画风名称”素材包。
Motion Prompt #195

含义：只用墨色浓淡与晕染来画
示例内容：同一张线稿变成和纸上的单色水墨画，仅用墨色浓淡、晕染和柔和的水洗效果塑造形象。
动效规格：
- 媒介：和纸上使用单一黑墨
- 外观：仅以浓淡墨色、晕染和柔和水洗效果绘制，不使用彩色
- 示例：将同一张基础草图（山丘上的房屋、树和太阳的线稿）作为参考交给图像模型，按此风格重绘。0.5 s 至 1.35 s，以斜向擦除从草图切换为该风格；画面缓慢放大至 1.045x，持续到 4.0 s；4.0 s 至 4.5 s 淡回草图（单次循环 = 4.7 s，cubic ease-in-out）
适用场景：适合留白充足、安静的日式画面。
