请使用“范围滑块（英文名：Range slider）”，它属于“UI 组件”素材包。
Motion Prompt #062

含义：双滑块选择最小值与最大值
示例内容：价格滑杆的左滑块向右拖、右滑块向左拖，以缩小范围，随后都返回原位。
动效规格：
- 542×191 卡片，循环周期 4.5 s。轨道位于 x 54–488、y 120，高 8；两个滑块之间为蓝色。范围 ¥0–¥10,000。
- 滑块：白色，半径 13，3 px 蓝色边缘；拖动时半径 15，带半径 24 的浅蓝色光晕。
- 低值滑块：1.0–1.6 s 从 0.1 → 0.3（¥1,000 → ¥3,000），3.55–3.9 s 返回。高值滑块：2.1–2.6 s 从 1.0 → 0.8（¥10,000 → ¥8,000），2.95–3.3 s 返回。均使用 easeInOutCubic。
- 每个滑块上方都有高 28 的数值气泡，拖动时蓝底白字。右上方以蓝字显示“¥1,000 – ¥10,000”，按 ¥100 的步长更新。
- 光标始终位于当前拖动的滑块上（在 1.0、2.1、2.95、3.55 s 按下）。
适用场景：适合按价格、日期、尺寸等带有最小值和最大值的范围进行筛选。
