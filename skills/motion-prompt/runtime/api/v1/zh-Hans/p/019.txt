Motion Prompt #019

含义：液体流入画面并替换场景
示例内容：颜料般的液体从顶部向下流淌并填满画面，变成下一场景。
动效规格：
- 白天 → 夜晚 → 白天，每段 2.35 s。两层液体均从上向下移动，使用二次方缓入缓出。
- 第 1 层（纯色，白天→夜晚用蓝色，夜晚→白天用珊瑚色）：0.35–1.5 s。第 2 层（下一场景本身，裁剪为液体形状）：0.7–1.8 s。
- 液体前缘从 y = −110 移动到底边下方 130 px。边缘叠加两个正弦波（振幅 13 px 和 8 px），中途起伏最强。
- 前缘垂下七道液滴（宽 30–54 px，圆头）；长度 = 基础值 30–110 px × (0.25 + 0.9 × 波强度)，中途最长。
- 融合效果：以白色绘制形状 → 模糊 7 px → 对 alpha 设阈值 → 填入颜色或下一场景。
适用场景：适合柔和、有机的转场，例如美食、美妆或创意视频。
