Motion Prompt #165

含义：持续摆动的波浪形区块分隔线
示例内容：蓝色区块与白色区块相接处，两层波浪形状持续缓慢摇动。
动效规格：
- 视口 511 × 168：上方为蓝色渐变区块 #3B64E8 → #8FA9F7，下方白色，交界处叠两层波浪。一轮 4.7 s，每个 9.4 s 素材包周期内重复两次。
- 后层波浪为白色、不透明度 0.45，中心 y = 100，由波长 260 px、振幅 8 px 与波长 130 px、振幅 4 px 的两个正弦波相加而成。
- 前层波浪为白色，中心 y = 110，由波长 300 px、振幅 9 px 与波长 110 px、振幅 3.5 px 的波相加，接入下方白色区块。
- 相位 a = 2π·t/4.7，后层使用 a + 1 和 −2a，前层使用 −a 和 2a + 0.5。每层的两个正弦波反向运动，因此形状持续变化，每 4.7 s 返回起始状态。
适用场景：适合希望区块边缘柔和而非笔直的页面，例如海洋、夏日或儿童主题网站。
