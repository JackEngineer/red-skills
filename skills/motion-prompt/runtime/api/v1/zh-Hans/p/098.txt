Motion Prompt #098

含义：后侧光勾勒主体边缘
示例内容：周围环境变暗，人物左后方和右后方的两盏灯只在头肩两侧勾出细亮边；右下方的俯视图标出两盏灯的位置。
动效规格：
- 场景 1：地平线位于 y 150，前方为头肩人像（头部中心 x 270、y 78，半径 29 px，无五官或头发）。
- 背景：明亮场景 → 暗场景（天空 #2B2D33、地面 #24252A）；人物 #4D5A75 → #1F2128。
- 亮边：将两个琥珀色 #FFC75A 的人物副本分别向左、右偏移 3.5 px，并向上偏移 2.5 px，放在深色人物后方（形成 3.5 px 宽的亮边）。
- 右下方俯视图（66×66 px）：灯光位于 ±135°（左后方和右后方）；右上角读数为“±135°”。
- 时间：效果在 0.4 s 至 1.4 s 之间显现，保持至 4.0 s，并在 4.8 s 前消失（单次 = 5 s，三次缓入缓出，约为 cubic-bezier(0.65,0,0.35,1)）。
适用场景：适合让人物或产品从暗背景中分离出来，突出外形。
