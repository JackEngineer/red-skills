Motion Prompt #231

含义：用人或物的图标数量表示比例
示例内容：十个人形图标排成一行，以灰色出现，前三个依次变蓝，“30%”从零递增。
动效规格：
- 人形：十个无面部特征的人形图标，高 80 px、间距 32 px，排成一行（排成网格会看起来像热力图）
- 入场：从 0.35 s 开始，间隔 0.06 s，各用 0.3 s 弹性出现（ease-out-back），均为灰色
- 变色：从 1.25 s 开始，间隔 0.22 s，前三个图标各用 0.25 s 从灰色变蓝
- 数值：左侧“30%”（46 px、蓝色）在 1.25 s 至 1.94 s 从 0 递增，下方显示“10 人中有 3 人”
- 结束：坐标轴和网格保留，仅数据在 4.15 s 至 4.55 s 淡出（单次循环 = 4.7 s）
适用场景：适合把比例转化为直观的人数，便于不喜欢数字的读者理解。
