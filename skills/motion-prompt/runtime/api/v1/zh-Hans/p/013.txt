Motion Prompt #013

含义：形状像液体一样流动和融合
示例内容：团块拉长、分裂成液滴，然后重新融合成一团。
动效规格：
- 主圆（半径 44）：在 0.35–1.45 s 以 cubic-bezier(.7, 0, .2, 1) 向右移动 300 px，途中沿正弦弧线上升 34 px；在 2.7–3.8 s 按相同方式返回。
- 七个圆沿相同路径跟随，每个依次延迟 0.065 s，半径从 44 递减至 15，垂直摆动 ±6 px。
- 即使静止时，三个小圆（半径 15, 13, 11）也会在距主圆 34–64 px 之间进出，每周期两次。
- 融合效果：以白色绘制圆形 → 模糊 9 px → 对 alpha 设阈值（仅在 112–144 之间柔化）→ 给剩余部分填色。
- 填色为薄荷绿 → 蓝色 → 紫色（#7C5CFF）的对角渐变，主圆上有白色椭圆高光。
适用场景：适合为标志、背景和衔接动作营造柔软、有机的观感。
