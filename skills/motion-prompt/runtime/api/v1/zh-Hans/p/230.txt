请使用“组合图（柱形图＋折线图）（英文名：Combo chart (bar + line)）”，它属于“资料中常用的图解与图表名称”素材包。
Motion Prompt #230

含义：柱形和折线叠在一张图里（左右两个刻度）
示例内容：六根柱形按左侧刻度（灰色刻度线）向上生长，随后折线按右侧刻度（蓝色刻度线）从左到右绘出。
动效规格：
- 坐标轴：左轴及其五个刻度为灰色，右轴及其五个刻度为蓝色，带三条浅色网格线，整个循环中保留
- 柱形：六根宽 36 px 的浅蓝色柱形，从 0.4 s 开始，间隔 0.12 s，各用 0.36 s 向上生长（ease-out）
- 折线：3.5 px 蓝线在 1.3 s 至 2.2 s 以匀速从左到右连接六个点；数据点为圆环标记（半径 7 px），从 1.25 s 开始，间隔 0.18 s 弹性出现
- 结束：坐标轴和网格保留，仅数据在 4.15 s 至 4.55 s 淡出（单次循环 = 4.7 s）
适用场景：适合在同一图中展示两个单位不同的数值，例如销售额和利润率。
