Motion Prompt #234

含义：在一条线上按时间顺序排列事件
示例内容：一条线从左向右绘出；线头经过各节点时，圆点和月份标签在上下两侧交替出现，最后一个为蓝色。
动效规格：
- 线条：y = 106 处从 x = 36 到 x = 503（深灰、3 px），在 0.4 s 至 2.0 s 绘出（cubic ease-in-out），右端带箭头
- 圆点：五个（4 月、6 月、8 月、10 月、12 月：4月 … 12月），在线头到达时各用 0.25 s 弹性出现（半径 7 px；最后一个为蓝色、10 px）
- 标签：每个圆点交替向上或向下，用 0.3 s 长出 22 px 的短竖线，连接 64×32 px 的圆角标签（白底、月份文字 18 px；最后一个为蓝底白字）
- 结束：整个图形在 4.1 s 至 4.5 s 淡出，卡片保持空白，直到 4.7 s 循环重新开始
适用场景：适合按时间顺序展示事件，例如历史、事物的发展经过或计划。
