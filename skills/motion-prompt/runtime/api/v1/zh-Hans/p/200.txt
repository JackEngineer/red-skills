Motion Prompt #200

含义：黑色铅条分隔的透光彩色玻璃
示例内容：同一张线稿变成由黑色铅条分隔的彩色玻璃画；天空、山丘、房屋和树分别成为透光的彩色玻璃片。
动效规格：
- 材料：以铅条拼接彩色玻璃片，如玻璃窗
- 外观：粗黑线分隔各个色块，光线透过时发亮
- 示例：将同一张基础草图（山丘上的房屋、树和太阳的线稿）作为参考交给图像模型，按此风格重绘。0.5 s 至 1.35 s，以斜向擦除从草图切换为该风格；画面缓慢放大至 1.045x，持续到 4.0 s；4.0 s 至 4.5 s 淡回草图（单次循环 = 4.7 s，cubic ease-in-out）（此示例采用略宽的裁切范围，以展示山丘的铅条）
适用场景：适合庄严或喜庆、具有透光感的装饰画面。
