Motion Prompt #017

含义：扩大的形状内部显现下一场景
示例内容：圆形或星形窗口逐渐扩大，内部显露下一个场景。
动效规格：
- 白天场景 → 夜晚场景 → 白天场景，每段 2.35 s。每半段的切换在 0.45–1.6 s 进行，历时 1.15 s，使用三次方缓入缓出。
- 下一场景绘制在当前场景上方，并裁剪为指定形状；形状不断扩大，直到覆盖画面。
- 白天→夜晚：圆形从太阳中心（112, 104）扩大，半径 0→470。
- 夜晚→白天：五角星从月亮中心（427, 104）扩大，外半径 0→1150，扩大的同时旋转 1.2 rad（约 69°）。
- 扩大时，形状边缘带白色描边，线宽 7。
适用场景：适合从画面中的太阳、标志或按钮等物体处开始转场。
