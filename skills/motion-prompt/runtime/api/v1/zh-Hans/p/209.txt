Motion Prompt #209

含义：用方格像素画出的游戏风
示例内容：同一张线稿变成由方形像素组成的平面游戏风格画面，没有纵深，每个像素都清晰可见。
动效规格：
- 外观：低分辨率，每个方形像素均清晰可见
- 视角：正面平视的平面画面，无纵深（立方体搭建效果参见体素艺术 #210）
- 示例：将同一张基础草图（山丘上的房屋、树和太阳的线稿）作为参考交给图像模型，按此风格重绘。0.5 s 至 1.35 s，以斜向擦除从草图切换为该风格；画面缓慢放大至 1.045x，持续到 4.0 s；4.0 s 至 4.5 s 淡回草图（单次循环 = 4.7 s，cubic ease-in-out）
适用场景：适合游戏风格或复古风格的图标和横幅。
