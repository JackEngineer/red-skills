Motion Prompt #107

含义：延长快门时间，让移动光源留下轨迹
示例内容：街道变成夜景，行驶中的汽车几乎消失，红色尾灯轨迹在车后延伸，对向车道出现白色和琥珀色光轨。
动效规格：
- 场景 2：街角，建筑、树木和路灯（x 114、292、494）位于 y 132–162 的道路后方；人物站在左前方（脚部位于 x 176、y 200，身高 124 px）。颜色变为夜景（天空 #2C3B5E，每三扇窗中的一扇为 #FFC75A）。
- 汽车：每 5 s 从 x −60 → 600；车身不透明度 100% → 10%。
- 尾灯轨迹：从 x −60 延伸到汽车位置，y 145 处为 #FF5B4D、2.6 px，y 149 处为 #FF8A6E、1.4 px。
- 对向车道：贯穿画面宽度的光轨分别为 y 135 处 #FFE9B8、2.6 px，y 138.5 处 #FFC75A、1.6 px，y 141.5 处 #FFE9B8、1.2 px（随效果淡入）。
- 右上角快门速度 1/250 → 8″。
- 时间：效果在 0.4 s 至 1.4 s 之间显现，保持至 4.0 s，并在 4.8 s 前消失（单次 = 5 s，三次缓入缓出，约为 cubic-bezier(0.65,0,0.35,1)）。
适用场景：适合在一张照片中表现车流，或呈现丝滑的流水与云层。
