请使用“长镜头（英文名：Long take）”，它属于“镜头运动与转场（第 2 弹）”素材包。
Motion Prompt #172

含义：不切换，一个镜头连续拍到底
示例内容：一个没有剪切的连续镜头跟随行走的人物，底部条带始终是一整条，没有断点。
动效规格：
- 衔接：无；一个镜头连续跟随人物 4.2 s（#041 跳切将其分成五段）。
- 主体：人物以恒定速度从左前方（x = -3.4 m，纵深 5.2 m）走向右后方（x = 2.8 m，纵深 9.6 m）；腿和手臂按 sin(t×7)×0.42 rad 摆动。
- 相机：跟随人物向右横移 0 m → 1.4 m，同时转向，yaw = atan2(person x - camera x, depth)×0.8；高度 1.4 m。
- 底部条带：一整条蓝色条带，标有“一镜到底，无切镜”并带有播放头，表示没有中断。
- 返回：在 4.2 s 停止，最后 0.5 s 交叉淡化回起点（单次 = 4.7 s）。
- 右上角读数显示已用时间（无切镜 0.0s → 4.2s）。
适用场景：适合保持连续的紧张感和临场感，或把一系列动作展现为一个流畅过程。
