请使用“扁平插画（英文名：Flat illustration）”，它属于“图像生成常用的画风名称”素材包。
Motion Prompt #207

含义：只有平涂色块，没有线条和阴影
示例内容：同一张线稿变成仅由平涂色块构成的插画，没有轮廓线或阴影。
动效规格：
- 外观：仅以平涂色块构成形状
- 避免：轮廓线、阴影和渐变
- 示例：将同一张基础草图（山丘上的房屋、树和太阳的线稿）作为参考交给图像模型，按此风格重绘。0.5 s 至 1.35 s，以斜向擦除从草图切换为该风格；画面缓慢放大至 1.045x，持续到 4.0 s；4.0 s 至 4.5 s 淡回草图（单次循环 = 4.7 s，cubic ease-in-out）
适用场景：适合网站、应用或幻灯片中的简洁插画。
