Motion Prompt #216

含义：蓝底白线的设计图
示例内容：同一张线稿变成蓝底细白线的技术图纸，带少量尺寸标注线和辅助构造线。
动效规格：
- 外观：蓝色底面上的细白线图纸
- 线条：少量尺寸标注线和辅助构造线（示例无数字或文字）
- 示例：将同一张基础草图（山丘上的房屋、树和太阳的线稿）作为参考交给图像模型，按此风格重绘。0.5 s 至 1.35 s，以斜向擦除从草图切换为该风格；画面缓慢放大至 1.045x，持续到 4.0 s；4.0 s 至 4.5 s 淡回草图（单次循环 = 4.7 s，cubic ease-in-out）
适用场景：适合说明产品工作原理，或营造“正在规划中”的感觉。
