Motion Prompt #157

含义：悬停列表项时显示对应照片
示例内容：光标悬停于纯文字列表的一行时，该行照片在光标旁淡入，并跟随光标移动。
动效规格：
- 视口 511 × 168，纯文字列表四行，行高 39 px、名称字号 17 px。光标逐行向下移动，每行约 1 s。一次演示 4.7 s，每个 9.4 s 素材包周期内重复两次。
- 悬停行：名称在 0.25 s 内右移 8 px（三次方缓出），名称和右侧箭头变橙；离开时在 0.25 s 内恢复。
- 照片：该行的照片为 132 × 84、圆角 6、带投影，出现在光标右侧 26 px、略偏上方，垂直方向限制在窗口内部。
- 同一段 0.25 s 内，照片不透明度从 0 增至 1，缩放从 0.85× 增至 1×。照片无滞后地跟随光标；切换到下一行时，旧照片淡出，新照片淡入。
适用场景：适合保持轻量、纯文字形式的作品、项目或房源列表，同时让用户查看感兴趣条目的照片。
