Motion Prompt #217

含义：用重叠的圆表示共同点
示例内容：两个圆从两侧滑入并重叠，只有交集部分变为深蓝色。
动效规格：
- 圆：两个半径 78 px 的圆；左侧 A 为浅蓝填充、蓝色轮廓，右侧 B 为浅灰填充、灰色轮廓；仅重叠区域填充深蓝色
- 运动：0.3 s 至 0.7 s 淡入（ease-out）；随后在 0.5 s 至 1.6 s，两个圆心相对画面中点的位置从 ±150 px 移至 ±44 px（cubic ease-in-out）
- 标签：A 和 B（26 px）位于各圆靠外侧的位置
- #240 同心圆图将圆逐层嵌套；维恩图则把圆并排放置，仅部分重叠
- 结束：整个图形在 4.1 s 至 4.5 s 淡出，卡片保持空白，直到 4.7 s 循环重新开始
适用场景：适合在一张幻灯片中展示两个或多个事物的共同点与差异。
