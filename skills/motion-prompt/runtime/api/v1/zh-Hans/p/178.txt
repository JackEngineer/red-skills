请使用“高角度镜头（英文名：High angle）”，它属于“镜头运动与转场（第 2 弹）”素材包。
Motion Prompt #178

含义：从高处向下拍
示例内容：相机升高并向下俯拍，人物显得渺小，地面占据画面大部分。
动效规格：
- 相机：从 1.5 m 升至 4.5 m，同时俯仰角 0 → -0.5 rad（向下约 29°）；不前后移动。
- 时间：0.6 s 至 2.2 s（1.6 s），三次缓入缓出（约为 cubic-bezier(0.65,0,0.35,1)）。
- 主体：人物静止站在前方 5 m；相机向下看时，人物缩小并向下移动，地面网格占据画面大部分，地平线从顶部离开。
- 保持：2.2 s 至 4.2 s 保持高角度（#031 升镜头持续升至 9 m；13 鸟瞰镜头 以 90° 垂直向下看）。
- 返回：最后 0.5 s 交叉淡化回平视高度（单次 = 4.7 s）；右上角读数显示角度和高度（↘ 0° · 1.5m → ↘ 29° · 4.5m）。
适用场景：适合让人物显得脆弱或渺小，或从上方交代局面。
