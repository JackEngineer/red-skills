Motion Prompt #131

含义：文字沿线条或曲线流动
示例内容：一行文字沿波浪线流动，每个汉字随路径转向。
动效规格：
- 路径：y = 118 + 42·sin(2πx ÷ 330 + 0.6)，x = −70 至 609；下方 6 px 处以藏青色虚线显示，虚线 14/10、线宽 5。
- 重复显示“文字沿着波浪线前行 • ”（42 px，粗体，字距 2 px）。每个字符按弧长定位在路径上，并旋转至路径方向。
- 文字每 4.7 s 沿路径前进一个完整字符串的长度，保证循环衔接。
- 汉字为白色，圆点为黄色。
适用场景：适合让文字沿形状排列和运动，例如环绕标志，沿道路、河流或波浪流动，或形成循环文字带。
