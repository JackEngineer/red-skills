Motion Prompt #012

含义：一种形状平滑变成另一种
示例内容：形状与颜色同步平滑变化，依次从圆形变为方形、星形和心形。
动效规格：
- 四种形状，每种 1.175 s：圆形 → 带圆角的方形 → 星形 → 心形 → 回到圆形。基础半径 64。
- 每段先保持形状，再在结束前 0.62 s 至 0.04 s 之间变形成下一种，历时 0.58 s。
- 每条轮廓存储为 240 个点，同索引的点进行线性插值。进度使用 backOut (s = 1.6)，因此略微过冲。
- 颜色：蓝色 → 珊瑚色 → 黄色 → 薄荷绿，以二次方缓入缓出混合。
- 变形过程中，缩放按 1 + 0.07 × sin(π × progress) 膨胀。
- 下方有四个圆点，当前形状对应的点更大且带颜色。
适用场景：适合在不切镜的情况下，把一个图标或标志变成另一个。
