Motion Prompt #192

含义：用一连串短镜头压缩时间
示例内容：七个短镜头展现三十天的训练，镜头以硬切衔接，右上角的日期跳跃变化。
动效规格：
- 七个镜头通过硬切（0 帧）衔接：0.75 / 0.7 / 0.65 / 0.65 / 0.65 / 0.6 / 0.7 s（合计 4.7 s）；右上角日期跳跃为 第 1、3、7、12、20、28、30 天。
- 镜头：1 跟拍跑步者（腿部按 t×14 运动），2 公园中跳跃，3 日出（太阳从 4 m 升至 12 m），4 低角度拍摄举起双臂，5 城市中行走（焦距 420 px），6 绕人物从 -0.3 环行至 +0.3 rad，7 在旗帜前举起双臂。
- 三十天训练浓缩为 4.7 s；每个镜头都改变相机位置、高度和焦距（#041 跳切保持同一构图）。
- 底部条带：七段，仅当前镜头为蓝色；最后 0.3 s 交叉淡化回第一个镜头的起点。
适用场景：适合在短时间内展现长期的变化或努力。
