Motion Prompt #127

含义：正放后倒放，反复来回
示例内容：方块移动到一端后，像倒放一样沿原路返回，反复往返。
动效规格：
- 每 4.7 s 往返一次，先正向播放 2.35 s，再将同一动作倒放 2.35 s；进度 g 线性地从 0→1→0。
- 薄荷绿圆角方块（48 px，圆角半径 13）从 x = 92 跳到 447，沿三段高度为 62·|sin(3πg)| 的拱形轨迹运动，并随 g 转一整圈。
- 四个残影，时间间隔 0.045 s，不透明度 0.1–0.4。
- 下方播放条：正向时为蓝色并显示播放标签，反向时为珊瑚色并显示倒放标签。进度条及滑块随 g 移动。
- 两端转折点以竖柱标记。
适用场景：适合加载动画、待机动画，以及需要不切镜反复往返的动作。
