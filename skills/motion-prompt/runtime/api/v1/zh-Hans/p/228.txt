Motion Prompt #228

含义：用蛛网的形状比较多个项目
示例内容：在六轴蛛网状网格上，灰色多边形从中心展开，随后蓝色多边形展开并略有超调。
动效规格：
- 刻度：四个嵌套六边形，最大半径 86 px（最外层颜色较深），以及六条辐射轴，整个循环中保留
- 对比：灰色多边形（数值 0.46–0.74，填充不透明度 0.22）在 0.4 s 至 1.1 s 从中心展开（ease-out）
- 主体：蓝色多边形（数值 0.92、0.58、0.84、0.4、0.76、0.52；填充不透明度 0.28，轮廓 3 px，顶点带圆点）在 0.95 s 至 1.85 s 展开，以 55:45 混合 ease-out 和 ease-out-back，产生轻微超调
- 结束：坐标轴和网格保留，仅数据在 4.15 s 至 4.55 s 淡出（单次循环 = 4.7 s）
适用场景：适合比较多个指标的均衡程度，或比较两个对象的长处与短处。
