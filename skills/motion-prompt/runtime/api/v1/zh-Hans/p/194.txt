请使用“厚涂油画（英文名：Impasto oil painting）”，它属于“图像生成常用的画风名称”素材包。
Motion Prompt #194

含义：颜料堆厚，笔触清晰可见
示例内容：同一张线稿变成色彩浓郁的厚涂油画，笔触和画刀痕迹形成明显的凸起。
动效规格：
- 媒介：厚涂油彩（impasto）
- 外观：笔触和调色刀痕迹保留为凸起的纹理，色彩浓烈厚重
- 示例：将同一张基础草图（山丘上的房屋、树和太阳的线稿）作为参考交给图像模型，按此风格重绘。0.5 s 至 1.35 s，以斜向擦除从草图切换为该风格；画面缓慢放大至 1.045x，持续到 4.0 s；4.0 s 至 4.5 s 淡回草图（单次循环 = 4.7 s，cubic ease-in-out）
适用场景：适合需要浓郁、厚重手工质感的海报和艺术作品。
