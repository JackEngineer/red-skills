Motion Prompt #128

含义：抽帧后动作一顿一顿
示例内容：星形以每秒约 8 帧的不连续步进跳过画面，每帧略有偏差。
动效规格：
- 每 4.7 s 共 38 帧，约每秒 8 帧，每帧保持约 0.124 s。只绘制这些帧，不绘制中间状态。
- 黄色星形（半径 38）从 x = −44 跳至 583，沿三段高度为 54·|sin(3πt)| 的拱形轨迹运动，并旋转两圈。
- 每帧使用固定的随机扰动，水平位置 ±5 px，竖直 ±4.5 px，旋转 ±0.15 rad，尺寸 ±5%。
- 前两帧以不透明度 0.28 和 0.12 保留，类似洋葱皮效果。
- 顶部和底部各有 26 px 黑色胶片条，带齿孔，并显示帧率标签。
适用场景：适合手工、黏土定格或拼贴风格，用于平滑动画显得过于精致的场景。
