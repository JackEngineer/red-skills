Motion Prompt #016

含义：远近图层以不同速度移动形成纵深
示例内容：风景横向平移，近景移动较多、远景较少，形成纵深感。
动效规格：
- 镜头平移：以正弦波在 ±108 px 之间运动，每 4.7 s 往返一次。
- 每层沿相反方向偏移，偏移量为平移量 × 系数。由后向前的系数依次为：星星 0.05，月亮 0.1，远山 0.28，中层山脊 0.6，前景山丘与树木 1.25，最近的深色形状 2.1。
- 远层颜色更暗、接近背景，近层更亮；最近一层是沿画面底部展开的大块深色剪影。
- 每层都向画面左右两侧至少延伸 200 px，确保边缘不会露出。
适用场景：适合为平面插画或照片增加纵深，例如背景、风景和滚动场景。
