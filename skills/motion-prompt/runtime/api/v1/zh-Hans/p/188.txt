Motion Prompt #188

含义：圆形窗口收拢，画面变黑
示例内容：圆形窗口围绕人物逐渐收拢，直到画面全黑，再在下一场景中重新打开。
动效规格：
- 圆形收拢：1.3 s 至 2.7 s（1.4 s），圆形窗口半径从 340 px 缩至 0（二次缓入缓出，约为 cubic-bezier(0.45,0,0.55,1)）；圆外为黑色（#141418）。
- 窗口中心：当前画面的主体投影到屏幕的位置，即 A 中人物的头部（左侧 0.6 m，高 1.63 m，距离 7 m），或 B 中的汽车（右侧 1.2 m，高 0.9 m，距离 9 m）。
- 全黑：2.7–3.1 s；2.9 s 时硬切换入下一画面。
- 圆形展开：3.1 s 至 4.4 s（1.3 s），圆形围绕下一画面的主体从 0 增至 340 px。
- 边缘：半径至少为 1 px 时，用 2 px 蓝色圆线标记边缘；两幅画面中相机均固定。
- 每 4.7 s 交替 A→B 和 B→A（往返 9.4 s）；右上角读数为“圆孔收拢” / “圆孔打开”。
适用场景：适合默片或卡通风格的结尾，或轻松俏皮的段落间隔。
