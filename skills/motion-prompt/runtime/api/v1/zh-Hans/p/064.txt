Motion Prompt #064

含义：通过页码切换列表页面
示例内容：点击页码 2、3，蓝色圆形标记移动，上方列表切换；最后返回第 1 页。
动效规格：
- 542×191 卡片，循环周期 4.5 s。“‹ 1 2 3 4 5 ›”居中位于 y 160，每个直径 36，间距 8 px。蓝色圆（半径 18）标记当前页，文字白色。
- 光标在 1.0 s 点击 2，2.1 s 点击 3，3.3 s 点击 1。
- 蓝色圆每页移动 44 px，每次以 easeInOutCubic 持续 0.2 s（从 3 返回 1 时一次移动 88 px）。
- 上方三行列表在 1.05、2.15、3.35 s 前后各 0.2 s 内，不透明度降落再恢复，1 → 0 → 1，并在最低点更换内容。
适用场景：适合将搜索结果、文章等长列表拆成带编号的页面。
