Motion Prompt #051

含义：从屏幕底部升起的面板
示例内容：手指轻点“查看详情”，面板从底部升起；向下拖动把手即可关闭。
动效规格：
- 542×191 卡片，循环周期 4.5 s。手指（半透明圆，半径 17，白色边缘）在 1.0 s 轻点“查看详情”胶囊按钮（170×36，底部中央）。
- 展开量：1.05–1.45 s 以 easeOutCubic 从 0→1。整卡遮罩为 rgba(18,20,28)，不透明度 0.36·a。
- 面板：白色，高 136，顶部圆角 18，上边缘 y = 191 − 136·a。阴影模糊 22，y 偏移 −4。顶部中央有 52×6 拖动把手。
- 内部包含粗体标题栏和两行带 26×26 图标的内容。
- 关闭：手指在 2.75 s 落到把手 (271, 68)，在 3.0–3.6 s 向下拖动；a 乘以 (1 − easeInOutCubic，作用于 3.0–3.6 s)，面板随手指移出底部。
适用场景：适合在移动端展示详情或选项，同时保留当前屏幕的上下文。
