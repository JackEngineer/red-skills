Motion Prompt #204

含义：以花草曲线勾边的装饰风格
示例内容：同一张线稿变成约 1900 年的海报：轮廓化为流畅粗曲线，树叶、草和太阳光芒化为藤蔓花卉装饰，环绕房屋与树。
动效规格：
- 外观：粗而流畅的曲线轮廓，以弯曲藤蔓和花卉装饰围成边框
- 配色：柔和的赭石色、橄榄绿和灰朱红
- 氛围：约 1900 年的海报（示例无文字）
- 示例：将同一张基础草图（山丘上的房屋、树和太阳的线稿）作为参考交给图像模型，按此风格重绘。0.5 s 至 1.35 s，以斜向擦除从草图切换为该风格；画面缓慢放大至 1.045x，持续到 4.0 s；4.0 s 至 4.5 s 淡回草图（单次循环 = 4.7 s，cubic ease-in-out）
适用场景：适合优雅而富有装饰感的包装、标签或海报。
