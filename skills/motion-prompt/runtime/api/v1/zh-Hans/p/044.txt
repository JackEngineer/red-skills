Motion Prompt #044

含义：两个镜头逐渐叠化切换
示例内容：下一幅画面叠在当前画面上，不透明度逐渐增加直到完全取代，中间阶段两者相互透出。
动效规格：
- 衔接：1.5 s 至 3.0 s，历时 1.5 s；后画面的不透明度从 0 → 100%。
- 缓动：二次方缓入缓出，约 cubic-bezier(0.45,0,0.55,1)，在 2.25 s 达到 50%。
- 前画面在下方保持完全不透明，后画面绘制在上方，不先将前画面淡出。
- 相机：两幅画面均固定，A 高 1.4 m，B 高 1.6 m、俯仰角 +0.1 rad；主体也都不动。
- 0–1.5 s 只显示前画面，3.0–4.7 s 只显示后画面。
- 每 4.7 s 在 A→B 和 B→A 间交替，往返 9.4 s；右上角显示“A → B” / “B → A”。
适用场景：适合表现柔和的时间流逝、地点变化，或进入回忆。
