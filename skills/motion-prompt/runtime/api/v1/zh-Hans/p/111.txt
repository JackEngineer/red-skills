请使用“色差（英文名：Chromatic aberration）”，它属于“摄影效果、光线与风格”素材包。
Motion Prompt #111

含义：高反差边缘出现不同颜色的色边
示例内容：街景被分成红、绿、蓝三个通道，以略有差异的尺寸重新叠加；人物、建筑和路灯边缘出现红色和青色镶边，越靠两侧越明显。
动效规格：
- 场景 2：街角，建筑、树木和路灯（x 114、292、494）位于 y 132–162 的道路后方；人物站在左前方（脚部位于 x 176、y 200，身高 124 px）。
- 分离：图像分别与红色 #FF0000、绿色 #00FF00、蓝色 #0000FF 相乘形成三个副本，再在黑底上相加。
- 围绕中心缩放：红色 1 + 2s，绿色 1 + s，蓝色 1，其中 s = 0 → 0.02。
- 偏移：左右边缘处红蓝通道最终相距约 11 px，中心处为 0。
- 时间：效果在 0.4 s 至 1.4 s 之间显现，保持至 4.0 s，并在 4.8 s 前消失（单次 = 5 s，三次缓入缓出，约为 cubic-bezier(0.65,0,0.35,1)）。
适用场景：适合增加老镜头的不完美感、VHS 质感或故障感。
