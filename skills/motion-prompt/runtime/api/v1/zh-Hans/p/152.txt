请使用“滚动放大（英文名：Zoom on scroll）”，它属于“落地页与网页效果（第 2 弹）”素材包。
Motion Prompt #152

含义：图片随滚动放大至铺满屏幕
示例内容：页面滚动时，中央的小照片逐渐放大并铺满窗口，周围文字淡出，照片上出现标题。
动效规格：
- 视口 511 × 168。滚动进度 p：0.3–2.3 s 从 0→1，3.0–4.4 s 从 1→0（三次方缓入缓出）。一次演示 4.7 s，每个 9.4 s 素材包周期内重复两次。
- 照片框从中央的 155 × 90（x = 178，y = 58，圆角 8）扩大至整个 511 × 168 窗口（圆角 0）；位置、宽度、高度和圆角均与 p 成比例变化。
- p 从 0→0.45 时，周围标题和正文淡出（不透明度 1 − 2.2p）。
- p 从 0.7→1 时，白色标题（26 px，字距 2 px）在照片中央淡入。滚动条滑块随滚动移动。
适用场景：适合旅行、房地产或品牌网站，让访客的注意力进入照片场景。
