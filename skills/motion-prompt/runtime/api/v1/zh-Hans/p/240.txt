Motion Prompt #240

含义：用嵌套的圆逐层缩小市场范围
示例内容：外圆、中圆和内圆从同一圆心依次放大，彼此嵌套，分别标注 TAM、SAM 和 SOM。
动效规格：
- 圆：三个共圆心的实心圆，半径分别为 91、61 和 31 px（从外向内为浅蓝、中蓝、深蓝），外圆的浅灰辅助圆环始终保留
- 运动：由外向内，间隔 0.45 s（0.4、0.85、1.3 s），每个用 0.5 s 从圆心放大，以 60:40 混合 ease-out 和 ease-out-back，产生轻微超调
- 标签：TAM 和 SAM 位于圆之间的环带中，SOM 位于内圆中（18 px）；各圆开始后 0.55 s 起，用 0.3 s 淡入
- 区别于 #217 维恩图：各圆逐层嵌套，而非并排放置
- 结束：整个图形在 4.1 s 至 4.5 s 淡出，卡片保持空白，直到 4.7 s 循环重新开始
适用场景：适合展示从整体逐步缩小到目标部分的范围，例如 TAM、SAM 和 SOM。
