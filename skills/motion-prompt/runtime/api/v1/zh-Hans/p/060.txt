Motion Prompt #060

含义：一排相连按钮用于切换视图
示例内容：点击“日、周、月”，蓝色选中背景横向滑动，下方柱状图高度随之变化。
动效规格：
- 542×191 卡片，循环周期 4.5 s。灰色 300×40 底座（圆角 10）位于 (121, 12)，分为三个宽 100 的分段，标注“日”“周”“月”。
- 选中背景：蓝色，92×32，圆角 8，阴影模糊 6；选中标签为白色。
- 光标在 1.0 s 点击周，2.1 s 点击月，3.3 s 点击日；选中背景每次以 easeInOutCubic 滑动 0.25 s。
- 下方图表有七根宽 34、间距 58 px 的柱（第六根蓝色）。高度在三组数据间变化（约 30–85、40–100、60–115），与选中背景同步并使用相同缓动。
适用场景：适合在同一内容的两至四个视图间切换，例如按日、周、月查看。
