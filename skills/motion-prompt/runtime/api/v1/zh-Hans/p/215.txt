Motion Prompt #215

含义：80年代风的霓虹网格与条纹夕阳
示例内容：同一张线稿变成 1980 年代的霓虹世界：地面是发光的紫色与青色网格，太阳是带横条纹的巨大落日，房屋和树以霓虹轮廓勾勒。
动效规格：
- 配色：紫色、青色和粉色霓虹
- 外观：地面霓虹网格、带水平条纹的巨大落日、霓虹轮廓
- 氛围：1980 年代复古未来主义
- 示例：将同一张基础草图（山丘上的房屋、树和太阳的线稿）作为参考交给图像模型，按此风格重绘。0.5 s 至 1.35 s，以斜向擦除从草图切换为该风格；画面缓慢放大至 1.045x，持续到 4.0 s；4.0 s 至 4.5 s 淡回草图（单次循环 = 4.7 s，cubic ease-in-out）（此示例采用更高的裁切范围，以展示地面网格）
适用场景：适合复古未来主义的音乐、游戏或活动视觉。
