请使用“低多边形（Low poly）（英文名：Low poly）”，它属于“图像生成常用的画风名称”素材包。
Motion Prompt #211

含义：用三角面拼成的3D
示例内容：同一张线稿变成完全由三角形面组成的 3D 画面；每个面有不同明暗，形体呈现分面效果。
动效规格：
- 构造：仅用无缝衔接的三角形面构成 3D 模型
- 外观：每个面有独立的颜色明暗，形成分面形体
- 示例：将同一张基础草图（山丘上的房屋、树和太阳的线稿）作为参考交给图像模型，按此风格重绘。0.5 s 至 1.35 s，以斜向擦除从草图切换为该风格；画面缓慢放大至 1.045x，持续到 4.0 s；4.0 s 至 4.5 s 淡回草图（单次循环 = 4.7 s，cubic ease-in-out）
适用场景：适合简洁现代的 3D 背景或图标。
