Motion Prompt #114

含义：以暗色为主，只突出受光部分
示例内容：画面大部分陷入黑暗，太阳消失，只有半身像受侧光照亮的右边缘保持明亮；直方图峰值向左端移动。
动效规格：
- 场景 3：左侧为半身像（头部中心 x 140、y 82，半径 28 px），右侧有山丘、房屋、树木和太阳（x 432、y 54，半径 15 px）。
- 颜色：天空 #FAF9F7 → #2B2D33，山丘 → #313339 和 #36383E，地面 → #24252A，人物 → #25272E；太阳及光环变成天空色并消失。
- 半身像受光的右边缘保留，#FFC75A → #FFB547。
- 直方图：峰值中心 0.56 → 0.14，宽度 0.2 → 0.08。
- 时间：效果在 0.4 s 至 1.4 s 之间显现，保持至 4.0 s，并在 4.8 s 前消失（单次 = 5 s，三次缓入缓出，约为 cubic-bezier(0.65,0,0.35,1)）。
适用场景：适合奢华、紧张或神秘的画面。
