请使用“滚动固定（英文名：Pinning）”，它属于“落地页与网页效果”素材包。
Motion Prompt #076

含义：区块固定，滚动推动内部内容变化
示例内容：藏青色区块填满视口后固定不动；继续滚动，数字和照片依次从 1→2→3 切换，随后区块继续滚走。
动效规格：
- 滚动：0.3–3.0 s 从 0→500 px，3.5–4.5 s 从 500→0（三次方缓入缓出）。
- 区块高 168、藏青色，在滚动 110 px 时抵达顶部，并在随后的 300 px 滚动中保持固定（GSAP ScrollTrigger pin）。
- 固定期间的进度：p = (scroll − 110) / 300。左侧长 124 的竖线随 p 逐渐填充橙色。
- 在 p = 1/3 和 2/3 时（±0.07，三次方缓入缓出）切换下一步：数字（46 px）向上滚动 52 px，照片（226 × 124）向上滑动 124 px。
- 经过 300 px 后解除固定，区块与下方白色区块一起向上滚动。
适用场景：适合在同一屏内逐步介绍流程、功能或前后对比。
