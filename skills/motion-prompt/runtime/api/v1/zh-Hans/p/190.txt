请使用“交叉剪辑（英文名：Cross-cutting）”，它属于“镜头运动与转场（第 2 弹）”素材包。
Motion Prompt #190

含义：交替呈现同时发生的两个场景
示例内容：跑步者和汽车两个同时发生的场景交替出现，剪切间隔越来越短。
动效规格：
- 两个场景共用同一时钟：A 是跑步者（左侧 0.3 m，纵深 15 m → 4.5 m，腿部按 u×12 运动），B 是城市中的汽车（右侧 1 m，纵深 17 m → 4.5 m）；两者均在 4.7 s 内靠近。
- 剪切：在 0 / 1.1 / 2.0 / 2.7 / 3.3 / 3.8 / 4.2 / 4.5 s 处在 A 和 B 之间硬切；镜头时长依次缩短为 1.1 → 0.9 → 0.7 → 0.6 → 0.5 → 0.4 → 0.3 s，以增加紧张感。
- 另一场景显示时，每个场景仍继续推进（切回来时主体已移动）。
- 相机：A 高度 1.3 m，固定，前景有四根柱子；B 高度 1.6 m，俯仰角 +0.06 rad，固定，场景含城市和太阳。
- 底部条带：A（灰色）和 B（蓝色）交替的八段，带播放头；最后 0.3 s 交叉淡化回 A 的起点。
- 右上角读数为“场景 A” / “场景 B”。
适用场景：适合在同时发生的事件之间制造紧张感，例如追逐或救援。
