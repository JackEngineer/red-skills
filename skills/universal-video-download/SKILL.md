# 通用视频下载与交付

## When to Use

用户发送视频网址、分享文字、视频直链或本地视频文件，要求下载、保存或重新交付时使用。不是“任意视频必成功”的承诺。不绕过登录、验证码、付费墙或加密保护。

## 使用方式

读取 references/使用说明.md，调用 scripts/download.py。完整视频下载、校验、压缩和失败信息必须以真实执行为准。仅使用用户本次提供的目标，不能拿旧视频冒充新结果。

```text
python3 <本技能目录>/scripts/download.py "<分享文字、网址或本地文件>" --name "中文主题"
```

## 处理规则

1. 从分享文字提取并去重全部链接；本地文件只整理校验，不声称从网站下载。
2. 抖音链接交给随附 scripts/douyin.py；其他网址交给 yt-dlp 网站/通用提取器，包含其能识别的公开网页、MP4/HLS等流地址。不保证所有站点或链接成功，不因存在提取器就宣称已实测。
3. 商城页、动态网页等脚本未覆盖时，读取 references/抖音与商品页经验.md，由助手检查公开内置播放器。此步骤需另有浏览器能力，不是自动化脚本承诺。
4. 不读取私人浏览器凭证、不绕过登录和付费/加密保护。遇到访问限制明确报告，不能无限重试。
5. 每个目标单独暂存；ffprobe 必须确认视频流、有效时长和大小后才能输出 downloaded_verified。失败记录 failed，不用空文件或 HTML 冒充视频。
6. 默认超过80MiB或编解码不兼容时保留原件，另生成 H.264/AAC MP4，目标约60MiB；大小不是平台硬限制。转换失败明确保留原件及警告，不谎称转换完成。
7. results.json 记录本次各项结果，每处理一项就保存一次；下一次执行会替换清单，但视频名有随机后缀，不覆盖之前视频。取消立即停止后续目标。
8. 用户要接收文件时发送已校验输出路径的 MEDIA 行。脚本不具备微信投递接口、重试队列或回执能力；没有平台证据不说用户收到。

## 验证与局限

运行 `python3 <本技能目录>/scripts/test_download.py`。测试使用明确标注的本地生成样片，不充当外网下载成功证据。外网和平台能力以 references/验证报告.md 为准。本包不含浏览器安装文件、模型或账号，不是完全离线安装包。
