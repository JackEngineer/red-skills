# 通用视频下载

粘贴视频分享文字、网页地址或视频直链，即可逐条尝试保存。也可以提供本地视频文件，检查视频信息并在需要时生成兼容版 MP4。

## 处理视频

1. 确认用户要处理的链接或文件。只处理本次提供的目标。链接中的访问参数可能写入本地结果清单，交付时只展示用户需要的文件和摘要。
2. 检查当前助手是否能运行本地命令并访问目标。缺少运行能力时，提供本地命令供用户运行。依赖安装和命令示例见[运行说明](references/usage.md)。
3. 从技能目录运行统一入口。将分享文字或路径作为独立参数传入，优先用运行环境的参数数组接口。

   ```sh
   python3 scripts/download.py --name "视频主题" -- "视频链接、分享文字或本地文件路径"
   ```

4. 只处理用户有权保存的内容。遇到登录、验证码、付费、DRM 或明确拒绝访问时，停止该目标。有官方保存入口时指引用户使用。
5. 读取本次命令的 JSON 输出，逐项交付已校验的文件、时长和大小。用户输入本地文件时，报告已整理。部分失败时保留成功文件，并说明失败原因。当前助手支持附加文件时使用附件，否则给出实际保存路径。

## 支持范围

- 视频直链和常见网页由 yt-dlp 提取。可用性随站点和提取器版本变化。
- 普通抖音视频使用独立浏览器会话打开公开页面。商品页按[商品视频保存指引](references/usage.md#商品视频)处理。
- 默认保存到 `~/Downloads/videos`。文件超过 80 MiB 或编码需要转换时，保留原件并生成 H.264/AAC MP4，目标约 60 MiB。以实际输出大小为准。

脚本需要带命令执行权限的本地环境。联网下载、浏览器和文件附件能力取决于当前助手。
