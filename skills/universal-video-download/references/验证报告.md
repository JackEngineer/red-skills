# 通用视频技能包验证报告

## 已执行并通过

运行 scripts/test_download.py：4项测试通过。

1. 分享文字中的多个链接提取、去重，以及抖音/非抖音域名路由（不把 notdouyin.com 误判为抖音）。
2. 用 ffmpeg 明确生成1秒蓝色视频样片，在本机临时 HTTP 服务器发布，调用通用入口通过 yt-dlp 实际下载，核对结果清单、视频时长和安全文件名。
3. 本地生成的视频作为输入，强制触发转码/压缩；保留原件并生成可由 ffprobe 校验的 H.264 通用版。
4. 把 HTML 写入 .mp4 测试夹具，脚本正确返回失败，不报告下载成功。

这些是受控功能验证；测试样片绝不是用户要求下载的原始视频，也没有用作外网下载成功的替代证据。

通用入口 --help 可正常执行。当前测试环境的 yt-dlp 版本为2026.07.04，这不是“已核验最新版本”的声明。

## 外网实际尝试

两条公开测试直链分别返回403/访问限制，没有下载成功：

- W3C 视频样例域名：提取器报告403，反自动化挑战。
- Google 存储视频样例：提取器报告403 Forbidden。

因此不能声称本次在外网平台进行了全流程成功验证。抖音子模块来自此前本会话实际成功的流程；前一个打包测试还遇到短链及CDN域名解析失败。本通用包没有重复冒充该路径已恢复。
