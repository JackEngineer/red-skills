# 通用视频下载技能包

## 能做什么

统一入口处理：

- 抖音公开视频（随附专用提取脚本）。
- yt-dlp 能识别的网站视频页面及普通网页嵌入视频。
- 可访问的公开视频直链（例如 MP4、非加密 HLS/m3u8）。
- 已经发送并保存到本机的视频文件：校验、复制、必要时转码/压缩，而不是重新下载。
- 一段分享文字中的多个链接：逐项处理，输出成功及失败清单。

不是“任何视频都保证下载”的工具。平台支持依赖提取器版本和网站当前规则，支持列表也不代表每个链接可用。登录、验证码、付费、DRM加密、删除、私密和网络阻断都可能导致失败。本脚本不自动处理商品页和任意动态网页；相关浏览器辅助经验已随附。

## 准备

建议在解压后的技能目录创建独立环境，不修改 Hermes 的生产环境：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r references/requirements.txt
python -m playwright install chromium
```

Windows 激活命令为 `.venv\Scripts\activate`。依赖安装需要联网。

系统需要 ffmpeg、ffprobe，抖音路径还需要 curl。macOS 用户可用自己的软件管理工具安装 ffmpeg。ffmpeg 必须包含 libx264/AAC 编码器才能生成通用版。非抖音下载不需要 Playwright；只有抖音专用流程需要。其他操作系统未做实机验证，通用路径采用跨平台 Python/命令行接口。

## 运行示例

在本技能目录运行：

```bash
python scripts/download.py "你复制的完整分享文字" --name "视频主题"
python scripts/download.py "视频网页网址" --output-dir "$HOME/Downloads/videos"
python scripts/download.py "链接一" "链接二" --name "一组视频"
python scripts/download.py "/已有视频的绝对路径/视频.mp4" --name "整理视频"
python scripts/download.py --help
python scripts/test_download.py
```

默认保存到当前运行用户的 Downloads/videos。文件名自动清理并添加随机后缀，不依赖原机器用户名。

抖音浏览器启动失败时可加：

```bash
--browser "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
```

抖音专用脚本会优先使用内置 Chromium；macOS 可回退到已安装的 Chrome，不修改用户现有浏览器配置。

## 输出与交付

results.json 是本次结果清单，后一次调用会替换它；每完成一个目标立即更新一次。程序返回0表示全部目标已下载并校验，返回1表示有失败；部分成功不等于全部成功。

- downloaded_verified：文件存在且能读取到视频流、有效时长和大小。
- failed：读取 error 了解原因；没有伪造成功文件。
- warning：例如原件已保存，但转码没有完成。

ffprobe 解析通过不等于完整逐帧播放验证。默认超过80MiB时保留原件另生成目标约60MiB版本，实际大小可能偏离，按最终输出核对。通过 `--compress-above-mib` 和 `--target-mib` 调整；它们不是微信官方大小限制。

助手发送文件时使用独立一行 `MEDIA:/绝对路径/视频.mp4`。本包不含微信机器人登录、投递接口或重试队列。要实现“微信发链接自动回视频”，仍需由已连接消息通道的助手调用本入口。

## 安装为 Hermes 技能

将整个 universal-video-download 目录放入当前配置档的 skills 目录。不要覆盖已有同名目录，先备份比较；不修改其他配置档。开启新会话后让助手读取这个技能。包里有完整抖音辅助脚本，不依赖另外安装原抖音技能。

## 隐私、费用和边界

脚本本身不调用大模型接口，不需要模型密钥，但由助手调度时助手仍可能消耗额度。本包不包含账号、Cookie、聊天记录、用户视频或软件安装包。

只下载自己有权保存的公开内容。不自动读取浏览器登录态，不绕过付费墙或加密，不以页面能播放为理由承诺能下载。外网测试和离线测试的区别见验证报告。
